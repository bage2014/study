# 副业Idea：基于GitHub的Java教育学习产品（Learn-by-Coding）

## Idea概述

将GitHub作为"学习平台基础设施"，打造"在GitHub上学Java"的系列教育产品：代码仓库式课程、交互式练习、开源项目实战营、面试题库等。用真实代码环境代替传统视频课程，10年Java经验直接转化为教学资产。

> 核心理念：**学代码最好的方式是写代码，写代码最好的地方是GitHub**。把你的10年Java经验包装成可复用、可分发、可收费的学习型GitHub仓库矩阵。

## 关键技术：自动化批改方案（核心壁垒）

### 方案一：GitHub Actions自动测试（适合算法/API题）
```yaml
# .github/workflows/grade.yml
# 学员Push后自动跑测试，生成得分报告回写到Commit Status
- name: Run tests and grade
  run: mvn test
- name: Calculate score
  run: |
    PASS=$(grep -c "Tests run:.*Failures: 0" target/surefire-reports/*.txt)
    TOTAL=...
    curl -X POST -H "Authorization: Bearer ${{ secrets.GITHUB_TOKEN }}" \
      "https://api.github.com/repos/${{ github.repository }}/statuses/${{ github.sha }}" \
      -d "{\"state\": \"success\", \"description\": \"得分 $PASS/$TOTAL\", ...}"
```

### 方案二：AI自动PR Review（适合代码质量/架构题）
```
学员提交PR → Workflow触发 → 
调用LLM（GPT-4o / 通义千问）分析代码风格/规范性/性能 →
AI自动评论PR → 生成改进建议
```

### 方案三：CLI助教（本地+云端双模式）
```bash
# 学员本地安装批改工具
$ brew install java-grader
$ cd my-homework && java-grader submit
# 自动上传代码→云端评分→返回报告
```

## 长期坚持策略

### 内容复利模型
- 每写1道题/1个项目仓库 = 可被无数学员复用的资产
- 100个题仓库 × 每月被5000人搜索 = 持续SEO免费流量
- 课程仓库一次写好，卖1次和1万次成本相同

### 可持续节奏（每周投入）
| 阶段 | 时间投入 | 产出 |
| :--- | :--- | :--- |
| 启动（0-6月） | 每周10-15小时 | 每周新增10道题 + 每月1个小型训练营 |
| 增长（6-18月） | 每周6-10小时 | 每周更新5道题 + 季度大型项目课 |
| 稳定（18月+） | 每周3-5小时 | 维护答疑 + 偶尔更新内容 |

### 习惯养成
- **每解决一个Java问题**，就把它变成一道练习题入库
- **每月做1次直播答疑**（可做成回放录像再卖）
- **每个star/follower**都引导到私域（微信群/邮件列表）

### 抗风险原则
- 不依赖单一平台：GitHub+自有网站+微信公众号同步分发
- 不做重视频：视频录制成本高，坚持"代码为主文档为辅，少量视频做补充"
- 题库版本化：Java版本升级、Spring Boot升级时，题库一键跑CI验证有效性

## 为什么最适合你（10年Java背景+副业+长期）

1. **经验直接变现**：你10年踩过的坑、做过的架构、解过的bug，全是教学内容，不用学新东西
2. **不挑时间地点**：写题库、加新题、回复答疑，碎片时间可做
3. **复利+滚雪球**：每新增1道题、1个star、1个付费学员，都是在滚雪球，越往后越轻松
4. **个人IP自然成型**：3年后"GitHub上教Java的人"标签自然打上，主业/咨询/高薪机会自动上门
5. **零成本试错**：前3个月把Java-Interview-101做出来，没人买损失的只是几周末时间
6. **市场永远在**：Java不会死，求职不会停，年年有新人学Java
