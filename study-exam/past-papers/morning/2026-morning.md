### 已公开真实题干

#### 1. 某大型电商平台计划对其核心交易系统进行升级改造，要求新系统具备应对突发峰值流量（如"双十一"促销）的能力，并且需要在系统部分服务发生故障时，仍能保证核心交易链路的基本可用。以下哪种架构风格最适合该场景？（）

A. 单体架构　　B. 微服务架构　　C. 面向服务架构（SOA）　　D. 管道-过滤器架构

**答案：B**
解析：微服务将系统拆分为独立部署的小型服务，具备弹性伸缩与故障隔离能力，突发流量可对核心服务独立扩容，部分服务故障不拖垮整体。单体扩展性差；SOA 侧重企业内部集成；管道-过滤器适合数据处理流程。
考点：架构风格-微服务

#### 2. 在微服务架构设计中，关于服务发现机制的描述，错误的是（）。

A. 客户端发现模式中，服务消费者需要直接查询服务注册中心
B. 服务端发现模式中，客户端请求需要通过路由器进行转发
C. 服务注册中心需要具备高可用特性，通常采用集群部署
D. 相比客户端发现，服务端发现模式对服务消费者代码侵入性更强

**答案：D**
解析：客户端发现需消费者内置客户端库查询注册中心，**对消费者代码侵入性较强**；服务端发现中消费者只向固定路由器发请求，侵入性更低。D 说反了。
考点：微服务-服务发现

### 8. 专业英语

围绕**黑板架构（Blackboard Architecture）**展开，考查对架构思想的英文理解。核心段落：

> The blackboard architecture is a cooperative problem-solving model in which independent knowledge sources interact through a shared data structure. The blackboard holds the current problem state, intermediate results, and partial hypotheses, while multiple specialized knowledge sources read from and write to this common workspace without directly invoking one another. A control component monitors changes to the blackboard and decides which knowledge source to activate next.
