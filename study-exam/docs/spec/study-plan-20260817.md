## 阶段 2：专题突破（4 周）

> 目标：5 大核心专题深挖，第一遍真题启动

### 第 5 周（9/14 - 9/20）专题：质量属性 + 架构评估

- 6 大质量属性场景 + 战术（性能/可用性/安全性/可修改性/可测试性/易用性）
- ATAM 步骤 9 步 + 输出
- SAAM / ARID / SABB 对比
- 历年案例题中质量属性识别专项

### 第 6 周（9/21 - 9/27）专题：Web 架构 + 分布式

- Web 演进：单体 → 集群 → 分布式 → 微服务 → 云原生
- 负载均衡（DNS / 反向代理 / LVS / Nginx / F5）
- 缓存（CDN / 反向代理 / 本地 / 分布式 / 多级）
- 分布式：CAP / BASE / 一致性 / 分布式事务 / 分布式锁
- 消息中间件（Kafka / RabbitMQ / RocketMQ）

### 第 7 周（9/28 - 10/4）专题：数据库 + 大数据

- 范式 1NF-BCNF、反范式
- 分库分表（垂直 / 水平 / Sharding）
- 读写分离、主从复制、主主复制
- NoSQL（KV / 文档 / 列存 / 图）
- 大数据：批处理 / 流处理 / Lambda 架构 / Kappa 架构
- 数据仓库（OLAP / 维度建模 / 星型雪花）

### 第 8 周（10/5 - 10/11）专题：微服务 + 论文模板成型

- 微服务拆分原则、服务发现、API 网关、配置中心
- 服务治理：熔断、限流、降级
- DevOps / CI/CD / 容器编排（K8s）
- **本周必须产出 5 篇论文模板初稿**（见 essays/templates/）

**阶段 2 验收**：5 个专题可独立讲清；近 5 年真题上午 + 案例第一遍完成（不要求正确率）。
