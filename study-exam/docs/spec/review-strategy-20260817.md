# 复习思路与方法论

> 创建：2026-08-17
> 适用：系统架构设计师，Java 老手带中级基础

## 1. 整体策略：以"得分"为导向

不是"学完所有知识"，而是"45 分万岁"。优先级：
**架构核心 > 论文模板 > 案例套路 > 上午综合 > 边缘模块**

## 2. 三科差异处理

### 上午综合（输入型）
- **思路**：广度优先，速过教材 → 真题筛选高频
- **方法**：
  1. 通读教材第一遍（不记，建立印象）
  2. 真题驱动：做题 → 错题回查教材 → 标记重点
  3. 高频考点专项突破（如 14 种架构风格、质量属性战术）
- **避坑**：不要陷入数学推导、细节概念争论，5% 的英语题直接背单词

### 下午案例（套路型）
- **思路**：套路 > 知识，答题模板化
- **方法**：
  1. 5 大题型各准备 1 套答题模板
     - 质量属性识别：场景 → 属性 → 战术
     - 架构风格选择：场景 → 候选 → 优劣对比 → 选择 + 理由
     - 设计模式应用：模式名 → 解决问题 → 类图 → 代码片段
     - Web 架构：现状 → 瓶颈 → 方案 → 收益
     - 数据库优化：分析 → 手段（索引/缓存/分库分表/读写分离）→ 权衡
  2. 真题标准答案逐句拆解，抄写 5 套
  3. 关键词命中（如"质量属性场景六要素：刺激源/刺激/制品/环境/响应/响应度量"）

### 下午论文（输出型）
- **思路**：模板 + 真实项目，时间不够则项目可适当美化但不可虚构
- **方法**：
  1. **准备阶段（9/14-10/11）**：选 5 个高频主题，各写一篇模板
  2. **打磨阶段（10/12-11/01）**：限时 120 分钟手写
  3. **结构**（必须背）：
     - **摘要 300 字**：项目背景 + 我角色 + 用什么技术 + 解决什么问题 + 效果
     - **正文 2200 字**：
       - 项目背景 300 字（含我职责）
       - 主体 1500 字（3-4 个分论点，每个 400 字）
       - 结尾 400 字（效果 + 反思 + 改进方向）
- **避坑**：
  - 不要写成纯理论综述，必须有项目细节（团队规模、数据量、QPS）
  - 不要偏题（4 选 1 选最熟悉的）
  - 字数必须 2000+，少了直接扣分

## 3. 知识分层记忆

| 层级 | 内容 | 方法 |
|------|------|------|
| L1 必背 | 14 架构风格 / 6 质量属性 + 战术 / UML 9 图 / 23 设计模式分类 | 默写 + 抽查 |
| L2 熟悉 | ATAM 9 步 / 软工开发模型 / 中间件分类 / Web 演进 | 真题反复 |
| L3 理解 | 大数据栈 / 微服务治理 / 数据库优化 | 项目关联 |
| L4 印象 | 知识产权 / 数学 / 嵌入式细节 | 选择题蒙也行 |

## 4. Java 老手优势转化

你的强项直接用上：
- **Spring Cloud → 微服务架构题**（服务发现、网关、熔断、配置中心）
- **MySQL/Redis → 数据库优化题**（索引、分库分表、读写分离、多级缓存）
- **JVM/中间件 → 性能优化、可靠性题**
- **真实项目 → 论文素材**

**重点反哺**：选 1-2 个真实 Java 项目，整理成"通用项目案例"：
- 项目背景（行业、规模、团队）
- 我角色（架构师 / 核心 dev）
- 用了什么技术栈
- 遇到什么问题 + 怎么解决
- 量化结果（QPS、响应时间、可用性、成本）

> 这个项目案例库可在 80% 论文题中复用，是最高 ROI 的准备工作。

## 5. 错题与笔记体系

- 错题不抄题，记关键词 + 错因
- 按章节归档到 notes/ 对应文件
- 每周回顾本周错题，标记"已掌握 / 仍模糊 / 放弃"

## 6. 时间分配建议（每周 ~15h）

| 活动 | 占比 | 时长 |
|------|------|------|
| 看教材/视频（输入） | 25% | 3-4h |
| 做真题（输出） | 35% | 5-6h |
| 整理笔记/错题 | 20% | 3h |
| 背诵 | 10% | 1.5h |
| 论文练习 | 10% | 1.5h（阶段 2 起） |

## 7. 心态管理

- 12 周足够，但每天不能断（断 3 天回退 1 周）
- 第 4 周可能 plateau（瓶颈），正常，扛过去
- 论文最易让人放弃，第 8 周模板成型后豁然开朗
- 模考分低不代表考试，真题比模考简单

## 8. 应试技巧速查

### 上午综合
- 不会的题选 B 或 C（统计规律略高）
- 含"绝对""一定"的选项通常错
- 英语题看前后文，专业术语对得上即可

### 下午案例
- 答题点写编号 ①②③，阅卷按点给分
- 不会也要写，沾边就有分
- 画图题用铅笔（机考则用工具栏）

### 下午论文
- 字迹工整 > 字数 > 内容深度（机考则格式整洁 > 字数 > 深度）
- 摘要必须出现"项目名 + 我的角色 + 关键技术 + 效果"
- 正文分论点用"第一/第二/第三"明确标识
- 留 10 分钟检查字数和错别字
