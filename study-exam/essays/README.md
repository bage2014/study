# 论文练习

> 5 篇模板 + 限时练习

## 目录

- `templates/`：5 篇必准备模板
- 根目录：日常练习（按日期命名）

## 文件命名

```
essays/
├── templates/
│   ├── 01-web-architecture.md
│   ├── 02-architecture-style.md
│   ├── 03-quality-attributes.md
│   ├── 04-database-optimization.md
│   └── 05-microservices.md
├── 2026-10-15-practice.md
└── ...
```

## 写作流程（参考 notes/07-essay-topics.md）

1. 选题 10 分钟
2. 摘要 15 分钟（300 字）
3. 正文 80 分钟（2200 字）
4. 检查 15 分钟

## 自评分标准

| 维度 | 分值 |
|------|------|
| 项目真实 + 切题 | 20 |
| 论点清晰 | 20 |
| 论据充分 + 数据 | 20 |
| 结构完整 | 10 |
| 字数达标 | 5 |
| 目标分 | ≥ 50 |
