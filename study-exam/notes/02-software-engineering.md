# 02 软件工程

> 开发模型 + 需求工程 + 测试 + 配置管理 + 项目管理基础
> 占比：约 10-15%

## 1. 软件开发模型对比

| 模型 | 特点 | 优点 | 缺点 | 适用 |
|------|------|------|------|------|
| 瀑布 | 线性顺序 | 文档完整 | 难返工 | 需求稳定 |
| V 模型 | 测试驱动 | 测试早介入 | 灵活性差 | 严格行业 |
| 增量 | 分批交付 | 早期可用 | 需开放架构 | 大型项目 |
| 螺旋 | 风险驱动 | 风险可控 | 复杂 | 大型高风险 |
| 喷泉 | 迭代无间隙 | 适合 OO | 难管理 | OO 项目 |
| RAD | 快速开发 | 速度快 | 质量风险 | 中小规模 |
| 原型 | 早验证 | 减少误解 | 易当生产 | 需求不清 |
| RUP | 用例+架构+迭代 | 完整 | 重 | 大型 |
| 敏捷 | 短迭代 | 灵活响应 | 文档少 | 需求多变 |
| DevOps | 开发运维一体 | 持续交付 | 工具链复杂 | 互联网 |

## 3. 需求工程

### 3.1 需求分类
- 业务需求 / 用户需求 / 系统需求
- 功能需求 / 非功能需求 / 设计约束

### 3.2 需求获取方法
- 用户访谈 / 问卷调查 / 观察 / 原型 / JAD 联合开发

### 3.3 需求分析
- 结构化分析 SA：DFD（数据流图）+ DD（数据字典）+ 加工说明
- 面向对象分析 OOA：用例图 + 类图 + 状态图

### 3.4 DFD 层次
- 顶层 → 0 层 → 1 层 → ...
- 父子图平衡：输入输出一致

## 4. 软件设计

### 4.1 结构化设计 SD
- 结构图（HIPO）
- 模块化：内聚（高）+ 耦合（低）
- 内聚等级（高→低）：功能 / 顺序 / 通信 / 过程 / 时间 / 逻辑 / 偶然
- 耦合等级（低→高）：非直接 / 数据 / 标记 / 控制 / 外部 / 公共 / 内容

### 4.2 面向对象设计 OOD
- 封装 / 继承 / 多态
- 设计原则 SOLID：
  - S 单一职责
  - O 开闭原则
  - L 里氏替换
  - I 接口隔离
  - D 依赖倒置

## 5. 软件测试

### 5.1 测试分类
- 静态 vs 动态
- 黑盒 vs 白盒 vs 灰盒
- 单元 / 集成 / 系统 / 验收

### 5.2 黑盒测试用例
- 等价类划分 / 边界值 / 因果图 / 判定表 / 状态迁移 / 错误推测

### 5.3 白盒测试覆盖（强→弱）
- 路径 / 判定/条件 / 多条件 / 条件组合 / 判定 / 语句

### 5.4 测试阶段
- α 测试：开发环境，内部
- β 测试：用户环境，真实用户

## 9. 项目管理基础
