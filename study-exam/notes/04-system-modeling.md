# 04 系统建模

> UML + MDA + DFD
> 占比：约 5-10%，案例常出补图题

## 1. UML 9 种图（必背）

### 1.1 静态图（结构图）
| 图 | 说明 |
|----|------|
| 类图 Class | 类、接口、关系；最常用 |
| 对象图 Object | 类的实例快照 |
| 组件图 Component | 模块/组件依赖 |
| 部署图 Deployment | 硬件节点 + 软件部署 |

### 1.2 行为图
| 图 | 说明 |
|----|------|
| 用例图 Use Case | 参与者 + 用例 + 关系 |
| 状态图 State | 对象生命周期状态转换 |
| 活动图 Activity | 业务流程/算法 |

### 1.3 交互图
| 图 | 说明 |
|----|------|
| 序列图 Sequence | 时间顺序的消息 |
| 协作图 Collaboration | 对象关系 + 消息（UML 2 改名通信图） |

## 2. UML 关系

| 关系 | 含义 | 表示 |
|------|------|------|
| 泛化 Generalization | 继承 | 实线空心三角 |
| 实现 Realization | 接口实现 | 虚线空心三角 |
| 关联 Association | 引用 | 实线 |
| 聚合 Aggregation | 整体-部分（弱） | 实线空心菱形 |
| 组合 Composition | 整体-部分（强，生命周期同步） | 实线实心菱形 |
| 依赖 Dependency | 使用 | 虚线箭头 |

## 3. UML 扩展机制
- 构造型 Stereotype：`<<interface>>`
- 标记值 Tagged Value：`{version=2}`
- 约束 Constraint：`{ordered}`

## 4. MDA 模型驱动架构（OMG）

```
CIM（计算无关模型）→ PIM（平台独立模型）→ PSM（平台特定模型）→ 代码
```

- CIM：业务领域模型
- PIM：与平台无关的中间模型
- PSM：映射到特定平台（J2EE/.NET）
- 代码：自动生成

## 5. 结构化分析 SA

### 5.1 DFD 数据流图
- 外部实体：矩形
- 加工：圆形/圆角矩形
- 数据存储：双横线
- 数据流：箭头

### 5.2 分层规则
- 顶层 → 0 层 → 1 层 → ...
- 父子图平衡：输入输出一致
- 加工编号：1, 1.1, 1.1.1

### 5.3 数据字典 DD
- 数据项 / 数据结构 / 数据流 / 数据存储 / 加工逻辑

## 6. 面向对象分析 OOA

### 6.1 步骤
1. 识别参与者和用例 → 用例图
2. 识别类和对象 → 类图
3. 识别对象关系
4. 识别对象行为 → 状态图 / 顺序图

### 6.2 类识别方法
- 名词法：从需求文档中提取名词
- CRC 卡片：类-责任-协作者
