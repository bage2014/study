## 1. 计算机组成原理

### 1.1 CPU 结构
- 运算器：ALU + 累加器 + 状态寄存器
- 控制器：PC + IR + 指令译码器 + 时序发生器
- 寄存器组：通用 + 专用

### 1.2 存储系统层次
```
CPU 寄存器 → Cache (L1/L2/L3) → 主存 → 辅存
```
- 局部性原理：时间 + 空间
- 虚拟存储器：页式 / 段式 / 段页式

### 1.2.1 Cache 高速缓存（计算高频）
- 功能：缓解 CPU 与主存速度差；对程序员透明，由硬件完成
- **平均访问时间：t = h × t₁ + (1 − h) × t₂**（h 命中率，t₁ Cache 时间，t₂ 主存时间）
  - 例：h=95%，Cache 10ns，主存 100ns → t = 0.95×10 + 0.05×100 = **14.5ns**
  - 注意：Cache 未命中时是否先访 Cache 再访主存（串行）按题意，常见考法两者都访
- **三种地址映射**（主存块 → Cache 行）：

| 映射方式 | 规则 | 冲突 | 电路/利用率 |
|----------|------|------|--------------|
| 直接映射 | 主存块只能放固定行：行号 = 块号 mod Cache 行数 | 高 | 最简单，利用率低 |
| 全相联 | 任意行都可放 | 最低 | 比较电路最复杂，利用率高 |
| 组相联 | 先按组号定位组（mod 组数），组内任意行 | 中 | 折中，实际主流（如 8 路组相联） |

- 地址划分：直接映射 = 标记 Tag + 行号 + 块内地址；组相联 = Tag + 组号 + 块内地址
- 淘汰算法：LRU（最常用）/ FIFO / 随机 / LFU；写策略：写直达 Write Through（同时写 Cache 和主存）、写回 Write Back（淘汰时才写回，配脏位）
- Cache 不能放在"主存之外"扩大容量，只加速；命中率不随容量线性增长

### 1.2.2 磁盘与存储器
- 存取时间 = 寻道时间 + 旋转延迟 + 传输时间
  - 平均旋转延迟 = 转半圈时间 = 60/(2r) 秒（r 转/分）
- 磁盘调度算法：FCFS（先来先服务）/ SSTF（最短寻道时间，可能饥饿）/ SCAN 电梯算法 / C-SCAN（单向循环扫描）

### 1.3 指令系统
- CISC vs RISC
- 寻址方式：立即/直接/间接/寄存器/基址/变址/相对

### 1.3.1 ★ 指令流水线（必考计算）
- 原理：一条指令分 k 段（取指→译码→执行→访存→写回），多指令重叠执行
- **流水线周期 = 各段中最长一段的时间**
- **n 条指令执行时间 T = 一条指令完整时间 + (n−1) × 周期 = ΣΔtᵢ + (n−1)×Δt_max**
  - 各段等长（都为 Δt）时：**T = (k + n − 1) × Δt**
- 吞吐率 TP = n / T；最大吞吐率 = 1/Δt_max
- 加速比 S = 顺序执行时间 / 流水时间 = (n × ΣΔtᵢ) / T
- 效率 E = S / k（设备利用率，流水线时空图面积比）
- 例：4 段各 2ns，10 条指令 → T = (4+10−1)×2 = **26ns**，TP = 10/26
- 影响因素：转移指令、共享资源冲突、数据相关（解决：旁路转发、停顿气泡、乱序、分支预测）

### 1.3.2 性能指标
- MIPS = 指令条数 /（执行时间 × 10⁶）；MFLOPS = 浮点操作数/秒
- 主频 f = 1/时钟周期；CPI = 执行一条指令平均时钟周期数；执行时间 = 指令数 × CPI / f
- **Amdahl 定律**：某部件占比 p、提速 k 倍 → 总加速 S = 1 / ((1−p) + p/k)（即使部件无穷快，上限 1/(1−p)）

### 1.4 总线与 I/O
- 总线分类：数据/地址/控制
- I/O 控制方式：程序查询 / 中断 / DMA / 通道

### 1.5 数据表示
- 原码 / 反码 / 补码 / 移码
  - 正数三码相同；负数：反码=符号位不变其余取反，补码=反码+1；移码=补码符号位取反
  - n 位补码范围：**−2^(n−1) ~ +(2^(n−1) − 1)**；原码/反码：−(2^(n−1)−1) ~ +(2^(n−1)−1)
  - 计算机中有符号整数用补码（0 唯一表示，加减统一）；移码常用于浮点阶码
- 浮点数 IEEE 754：
  - 表示 = 数符 + 阶码（移码）+ 尾数（原码，规格化，隐含整数位 1）
  - 单精度 32 位：1 + 8 + 23；双精度 64 位：1 + 11 + 52
  - 加减运算：**对阶（小阶向大阶看齐）→ 尾数求和 → 规格化 → 舍入 → 判溢出**
- 校验码：
  - **奇偶校验**：只能检 1 位错，不能纠错
  - **海明码 Hamming**：检 2 位纠 1 位；校验位位数 k 满足 **2^k ≥ m + k + 1**（m 数据位）
    - 例：数据 8 位 → 2^k ≥ 8+k+1 → k=4；数据 16 位 → k=5
    - 校验位放 2⁰, 2¹, 2²…位置（第 1、2、4、8…位）
  - **CRC 循环冗余校验**：模 2 除法（异或），能检错不能纠错，广泛用于网络/磁盘；生成多项式做除数
  - 码距：码距越大检错纠错能力越强；码距 ≥ 3 可纠 1 位

### 1.6 可靠性基础（计算与 06 章联动）
- 串联系统 R = R₁×R₂×…×Rₙ（可靠性降低）
- 并联系统 R = 1 − (1−R₁)(1−R₂)…（可靠性提高）
- 混联：先并后串或先串后并，分步化简约分

## 2. 操作系统

### 2.1 进程管理
- 进程三态：就绪 / 运行 / 阻塞
- 五态扩展：新建 / 终止
- PV 操作（信号量）
  - P(S)：S=S−1，若 S<0 则阻塞等待；V(S)：S=S+1，若 S≤0 则唤醒一个等待者
  - S 初值 = 资源数量；S<0 时绝对值 = 等待进程数
  - 互斥信号量初值 1；同步信号量初值 0
- 经典同步：生产者消费者 / 读者写者 / 哲学家进餐
- 死锁四条件 + 处理（预防 / 避免 / 检测 / 解除）
  - 四条件（同时满足）：**互斥、请求保持、不可抢占、循环等待**
  - 预防：破坏后三个条件；**互斥无法破坏**（2024 真题考点）
  - 解除：资源剥夺、撤销进程、进程回退
- ★ 死锁资源计算（2024 真题）：
  - n 个进程，每个最多需 m 个同类资源，**不发生死锁最少资源数 R = n × (m−1) + 1**
  - 例：5 进程各最多 2 个 → R = 5×1+1 = **6**
- 银行家算法：系统安全状态判定——找能满足"最大需求−已分配 ≤ 可用"的进程，模拟回收后继续，全部能完成则安全

### 2.2 内存管理
- 分页 / 分段 / 段页式
  - 分页：固定大小页，对用户透明，一维地址，可能内碎片（最后一页）
  - 分段：按逻辑模块变长，用户可见，二维地址，易共享保护，有外碎片
  - 段页式：先分段再分页，集两者优点
- 逻辑地址 = 页号 + 页内偏移；物理地址 = 页框号 × 页大小 + 偏移（查页表）
  - 例：页大小 4KB（2¹²），逻辑地址十六进制 3A7C → 页号 3、偏移 A7C
- 页面置换：FIFO / LRU / OPT / CLOCK
  - **Belady 异常**：FIFO 可能分配帧数增多缺页反而增多；LRU/OPT 不会
  - OPT 最优（理论，往后看最久不用）；LRU 最常考（往回看最久未用）
- 快表 TLB：页表的 Cache，加速地址变换
- 缺页中断属于内中断（故障 fault），处理后重新执行该指令

### 3.2.1 ★ 信道速率（2025 真题奈奎斯特）
- **奈奎斯特定理（无噪声理想低通信道）**：
  - 最大码元速率（波特率）B = **2W**（W 带宽 Hz）
  - 最大数据率 = **2W × log₂V**（V 码元离散状态数/电平数）
- **香农定理（有噪声实际信道）**：
  - 最大数据率 C = **W × log₂(1 + S/N)**
  - 信噪比 dB 换算：**dB = 10 lg(S/N)**；如 30dB → S/N = 1000
  - 例：W=3kHz，30dB → C = 3000×log₂(1001) ≈ 3000×10 = **30 kbps**
- 两者都给取**较小值**（理论上限取交集）
- 易错：bps 与 Bps（字节）差 8 倍；波特率与比特率关系 R = B × log₂V

### 4.5 ★ 三级模式两级映像（2025 真题）
```
外模式 A（用户视图1）  外模式 B（用户视图2）   ← 用户级，可有多个
        │ 外模式-模式映像                │
        模式（概念模式/逻辑模式，全局逻辑结构，唯一）
        │ 模式-内模式映像
        内模式（物理模式，存储结构，唯一）
```
- **外模式（子模式/用户模式）**：用户看到的视图，可以多个；对应视图层
- **模式（概念模式/逻辑模式）**：全体数据的逻辑结构，**唯一**；对应基本表
- **内模式（物理模式）**：数据物理存储结构，**唯一**；对应文件/索引
- **两级映像保两个独立性（必考）**：
  - 外模式/模式映像 → **逻辑独立性**（改逻辑结构，改映像即可，外模式和应用不动）
  - 模式/内模式映像 → **物理独立性**（改存储结构，改映像即可，模式和应用不动）

### 4.6 ER 模型与分布式数据库
- ER 图：矩形=实体、椭圆=属性、菱形=联系；联系基数 1:1 / 1:N / M:N
- M:N 联系转关系模式必须**单独建表**，两端主键作外键 + 自身属性
- Armstrong 公理（函数依赖）：自反律、增广律、传递律（三条基本）；合并、分解、伪传递（导出）
- 并发控制：封锁（共享锁 S / 排他锁 X）；两段锁协议 2PL（扩展阶段只加锁、收缩阶段只解锁，保证可串行化但可能死锁）
- 分布式数据库：
  - 透明性层次：**分片透明（最高）→ 分配（位置）透明 → 局部数据模型（逻辑）透明**（层次降低）
  - CAP/BASE 理论见 [05-emerging-tech.md](05-emerging-tech.md)
- 数据仓库：面向主题、集成、相对稳定（非易失）、反映历史变化（时变）；OLAP 多维分析（星型/雪花模型）
