# 07 论文素材与模板

> 论文核心：1 个真实项目案例 + 5 篇模板
> 总分 75，及格 45，目标 50+

## 1. 项目案例库（核心资产）

> 在所有论文中复用。建议挑 1-2 个真实 Java 项目，整理成"通用案例"。

## 2. 论文结构（必背）

### 2.1 摘要 300 字
```
2026 年 x 月，本人参与了 xxx 公司的 xxx 系统建设，
担任系统架构师，负责 xxx。
该系统 xxx（业务背景 + 挑战）。
本文以该项目为例，讨论了 xxx 主题。
具体阐述了 xxx（3 个分论点）。
最终项目 xxx（量化效果），证明了 xxx 方案的有效性。
```

### 2.2 正文 2200 字
- **第一段 项目背景 300 字**：业务背景 + 团队 + 我的职责
- **第二段 主题概述 200 字**：相关理论简述（架构风格定义、质量属性概念等）
- **第三-五段 主体 1500 字**：3 个分论点，每个 500 字
  - 分论点 1：xxx
  - 分论点 2：xxx
  - 分论点 3：xxx
- **第六段 结尾 200 字**：效果 + 反思 + 改进方向

### 2.3 字数控制
- 摘要 280-320 字
- 正文 2200-2500 字
- 总 2500-3000 字（不少于 2000，超过 3500 阅卷疲劳）

## 3. 5 篇必准备模板（按 ROI 排序）

### 3.1 模板 1：Web 应用架构设计（最高频）

**主题**：负载均衡 + 缓存 + 高并发

**分论点**：
1. 多级负载均衡架构（DNS + Nginx + LVS）
2. 多级缓存设计（本地 + Redis + CDN）
3. 数据库读写分离 + 分库分表

**项目素材**：电商秒杀 / 高并发订单系统

### 3.2 模板 2：软件架构风格选择与论证

**主题**：从单体到微服务的演进

**分论点**：
1. 单体架构的瓶颈（耦合、部署、扩展）
2. 微服务架构选型与拆分原则
3. 服务治理（注册、网关、熔断、配置）

**项目素材**：老系统重构

### 3.3 模板 3：软件质量属性（性能/可用性）

**主题**：以性能和可用性为例

**分论点**：
1. 性能场景识别 + 战术（缓存/异步/水平扩展）
2. 可用性场景识别 + 战术（冗余/心跳/故障转移）
3. 架构评估方法 ATAM 在项目中的应用

**项目素材**：核心交易系统

### 3.4 模板 4：数据库设计与优化

**主题**：分库分表 + 读写分离 + NoSQL

**分论点**：
1. 读写分离架构（主从同步 + 路由）
2. 分库分表策略（垂直/水平/Hash/范围）
3. 引入 Redis + ES 补充关系型数据库不足

**项目素材**：用户中心 / 订单系统

### 3.5 模板 5：微服务架构设计

**主题**：微服务全栈方案

**分论点**：
1. 微服务拆分（DDD 限界上下文）
2. 服务治理组件（注册中心 + 网关 + 配置中心 + 链路追踪）
3. 容器化部署（Docker + K8s + DevOps）

**项目素材**：从 SOA 演进到微服务

## 6. 评分要点（来自阅卷经验）

### 加分项
- 项目真实（公司名、行业、规模、数据量化）
- 切题（紧扣所选主题，不堆砌）
- 论点清晰（3 个分论点明确）
- 论据充分（具体技术方案 + 数据）
- 结构完整（摘要 + 背景 + 主体 + 结尾）

### 扣分项
- 字数不足（<2000 直接扣大分）
- 偏题（套模板套错）
- 纯理论综述，无项目细节
- 摘要无"我"角色
- 字迹潦草（机考则格式乱）
