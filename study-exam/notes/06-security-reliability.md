# 06 信息安全与系统可靠性

> 安全 + 可靠性
> 占比：约 8-15%

## 1. 信息安全五要素

- 机密性 Confidentiality
- 完整性 Integrity
- 可用性 Availability
- 可控性 Controllability
- 不可否认性 Non-repudiation

## 2. 加密算法

### 2.1 对称加密（共享密钥）
- 加解密同一密钥，速度快
- 算法：**DES**（56 位，已不安全）/ **3DES** / **AES**（128/192/256）/ **IDEA** / **RC4** / **SM1/SM4**（国密）
- 缺点：密钥分发

### 2.2 非对称加密（公钥 + 私钥）
- 加解密不同密钥，速度慢
- 算法：**RSA** / **ECC** / **DSA** / **ElGamal** / **SM2**（国密）
- 公钥加密 → 私钥解密（保密）
- 私钥签名 → 公钥验签（不可抵赖）

### 2.3 哈希（摘要）
- 单向不可逆
- **MD5**（128 位，已不安全）/ **SHA-1** / **SHA-256** / **SM3**（国密）

### 2.4 数字信封
- 用对称密钥加密数据
- 用接收方公钥加密对称密钥
- 结合速度 + 安全

## 8. 系统可靠性

### 8.1 关键指标
- **MTBF** 平均无故障时间（越大越好）
- **MTTR** 平均修复时间（越小越好）
- **MTTF** 平均故障时间
- 可用性 A = MTBF / (MTBF + MTTR)

### 8.2 可靠性指标
- 失效率 λ
- 可靠度 R(t) = e^(-λt)

### 8.3 串联 / 并联系统
- 串联：R = R1 × R2 × ... × Rn
- 并联：R = 1 - (1-R1)(1-R2)...(1-Rn)

### 8.4 容错技术
- 冗余：硬件 / 软件 / 时间 / 信息
- N 版本程序设计（多版本独立实现，投票）
- 恢复块方法（主版本 + 备份版本）
- 检查点 / 回滚

### 8.5 RAID 磁盘阵列
| 级别 | 说明 | 利用率 |
|------|------|--------|
| RAID 0 | 条带 | 100% |
| RAID 1 | 镜像 | 50% |
| RAID 5 | 奇偶校验 | (n-1)/n |
| RAID 6 | 双校验 | (n-2)/n |
| RAID 10 | 镜像+条带 | 50% |
