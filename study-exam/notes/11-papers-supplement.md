## 一、计算机系统基础（上午）

### 1.1 计算机组成

| 考点 | 出处 | 核心结论 |
|------|------|----------|
| 存储层次 | 21-#14 | 寄存器 > Cache > 内存 > 硬盘；越上越快越贵越小 |
| Cache 映射 | 22-#9, 24-#52 | 只有直接映射/全相联/组相联三种，无"间接映射"【陷阱】 |
| RISC vs CISC | 22-#59, 23-#9, 25-#58 | RISC：定长指令、硬布线、单周期+流水线（ARM/RISC-V）；CISC：变长、微程序、寻址方式多（x86） |
| 流水线 | 23-#59 | 执行时间 T=(k+n−1)Δt；加速比 S=nk/(k+n−1)，n→∞ 时上限=段数 k；冲突三类：结构/数据/控制 |
| 存储器类型 | 25-#15 | PROM 一次编程；EPROM 紫外擦除；EEPROM 电擦除 |
| 编译六阶段 | 22-#15 | 词法→语法→语义→中间代码→优化→目标代码；需求分析不属于 |
| 动态语义错误 | 23-#15 | 数组越界/除零/死循环只能运行时发现；类型检查可静态 |
| 采样定理 | 23-#20 | fs ≥ 2×fmax（CD 44.1kHz ↔ 20kHz） |
| RAID | 21-#59 | RAID5 分布式奇偶校验坏 1 块；RAID1 镜像 100% 冗余；【拓展】RAID6 双校验坏 2 块、RAID10 先镜像后条带 |
| 校验码【拓展】 | 5 年未考、考纲内 | 奇偶校验：码距 2，只能检 1 位错不能纠；**海明码**：码距 3，可纠 1 位错，校验位数 k 满足 2^k ≥ n+k+1；CRC 循环冗余校验：只能检错不能纠错，用于链路层（生成多项式做模 2 除） |
| 数据表示【拓展】 | 考纲内 | 原码/反码/补码：负数补码=反码+1，补码 0 唯一；浮点数=阶码（决定范围）+尾数（决定精度），规格化目的是保精度；移码用于阶码 |
| Flynn 分类【拓展】 | 考纲内 | SISD 单处理器 / SIMD 向量机 GPU / MISD 无实际机器 / MIMD 多处理机集群 |

**【拓展】** 多核缓存一致性 MESI 协议（Modified/Exclusive/Shared/Invalid）；NUMA 架构（CPU 访问本地内存快）；流水线冒险解决：数据冒险→转发/停顿，控制冒险→分支预测；SSD 与机械盘差异（FTL、磨损均衡）——上午偶发 1 题。总线带宽=总线宽度×工作频率（如 64 位×66MHz）；CISC/RISC 之外注意**主频≠实际性能**，看 CPI/IPC 与 MIPS=指令数/(执行时间×10⁶)。

### 1.2 操作系统

| 考点 | 出处 | 核心结论 |
|------|------|----------|
| 进程三态 | 21-#2, 25-#45 | 就绪/运行/阻塞；挂起态非基本态 |
| 死锁四条件 | 22-#7, 21-#69 | 互斥/保持等待/不可剥夺/循环等待；"可剥夺"不在其中【陷阱】 |
| 死锁预防 | 23-#7, 24-#3 | 一次性分配破坏保持等待；有序分配破坏循环等待；**互斥不可破坏** |
| 银行家算法 | 23-#52 | 死锁**避免**（不是预防）；找安全序列 |
| 页式 vs 段式 | 21-#29, 22-#29 | 页式消外部碎片、有内部碎片；段式便于共享保护、有外部碎片 |
| TLB 快表 | 23-#29, 24-#30 | 加快虚实地址变换（命中率 >90%），不扩容不减缺页 |
| 页面置换 | 22-#69, 24-#34 | FIFO 有 Belady 异常；LRU/OPT 无 |
| 磁盘调度 | 23-#69 | SCAN 电梯单向到底折返；C-SCAN 单向循环；SSTF 就近 |
| SPOOLing | 23-#40, 24-#32 | 独占设备→共享虚拟设备（输入/输出井），提高设备利用率 |
| PV 操作 | 21-#53, 25-#44 | P 减 1，S<0 阻塞；V 加 1 唤醒 |
| 中断处理 | 24-#33 | 保护现场→中断服务→恢复现场；内存分配不属于 |
| 调度算法 | 22-#52, 24-#29 | RR 适合分时；FCFS 公平但周转长；【拓展】多级反馈队列=通用之王 |
| 文件系统 | 21-#40, 24-#31, 25-#22 | 多级目录解决重名；首次打开先读 FCB |

**【拓展】** 写时复制 COW（fork 高效）；协程=用户态轻量线程（Go/Java Loom），切换不走内核；时钟置换算法（LRU 近似）；大页/透明大页减 TLB miss。Java 视角：线程池参数与 OS 调度、mmap 零拷贝。
**【拓展·计算】** 周转时间=完成−到达；带权周转=周转/服务（≥1，越小越公平）；SJF 平均周转最短但可能饿死长作业；逻辑地址=页号+页内偏移（页大小 4KB→后 12 位为偏移）；物理块号查页表拼接偏移得物理地址。

### 1.3 数据库基础

| 考点 | 出处 | 核心结论 |
|------|------|----------|
| 三级模式两级映像 | 21-#3, 23-#3, 24-#24, 25-#27/28, m3-1/2 | 外/概念映像→**逻辑**独立性；概念/内映像→**物理**独立性【陷阱：两者互换】 |
| 完整性 | 22-#3, 23-#17 | 主键=实体；外键=参照；CHECK=用户定义 |
| 范式 | 21-#63, 22-#48, 24-#22, 25-#41/42, m3-4/11 | 2NF 消部分依赖→3NF 消传递依赖→BCNF 决定因素皆候选键→4NF 消多值依赖 |
| 候选键 | 23-#48, 25-#41 | 求 X⁺ 闭包覆盖全属性；F={A→B,B→C,A→D} 候选键=A |
| 自然连接 | 21-#48, 24-#23 | 去掉重复公共列：R(A,B,C)⋈S(C,D,E)=5 列 |
| 笛卡尔积 | 25-#7, 22-#48 | 属性数=相加、元组数=相乘 |
| E-R 转关系 | 21-#52, 24-#25, m3-12 | 1:1 并入任一方；1:N 并入 N 方；M:N 独立关系+组合主键 |
| ACID/隔离级 | 21-#42, 24-#26, 25-#43, m3-36/48 | 串行化才解幻读；可重复读仍可能幻读；读已提交解脏读 |
| 封锁/恢复 | 22-#51, 24-#27/28, m3-5/7 | 2PL 保证可串行化但**不防死锁**；UNDO 撤销未提交、REDO 重做已提交 |
| 分布式透明性 | 22-#56 | 分片透明最高 > 位置透明 |
| OLAP/OLTP | 23-#56 | OLAP 列存星型复杂聚合；OLTP 行存高并发小事务 |
| 索引 | 22-#63, 23-#42/51, m3-10/47 | B+树非叶只存索引、叶子链表；聚簇叶存数据行一表一个；InnoDB 回表 |
| SQL 优化 | m3-9/65 | 索引失效：列上用函数/!=/LIKE '%x' 前缀通配/隐式类型转换/NULL 判断；慢查询优化=索引+SQL+分库分表+缓存（加连接数无关） |
| 模式分解判定【拓展】 | 考纲内案例备选 | **无损连接**：分解后自然连接能还原原表（表格法 chase，或分解成两表时交集为任一方候选键即无损）；**保持函数依赖**：分解后各关系上依赖的闭包并集=原 F 闭包；规范化要求二者都保持 |
| 关系代数除运算【拓展】 | 考纲内 | R÷S 取 R 中有而 S 全部匹配的元组（典型场景："选修了全部课程的学生"）；五种基本运算=选择/投影/并/差/笛卡尔积，其余（交/连接/除）可由基本运算导出 |
|  Armstrong 公理【拓展】 | 考纲内 | 自反/增广/传递三条基本规则 → 导出合并/分解/伪传递；求候选键：只出现在左边→必在键中，只在右边→非键，两边都没出现→必在键中 |
| 视图/存储过程/触发器 | m3-56/60/63/69 | 视图=虚拟表简化查询，**不提升写性能**；存储过程=预编译 SQL 块（不自动建索引）；触发器时机 BEFORE/AFTER/INSTEAD OF（无 DURING）；连接池=复用连接/减开销/限并发 |
| OLAP 操作【拓展】 | 考纲内 | 下钻（细化）/上卷（汇总）、切片（固定一维）、切块（固定多维）、旋转（换维轴）；数据仓库四特点=面向主题/集成/相对稳定/反映历史变化 |

**【拓展】** MVCC 多版本并发控制（InnoDB ReadView + undo 链，快照读不加锁——面试与案例解释"可重复读如何防幻读间隙锁"必备）；Binlog 三格式 statement/row/mixed；GTID 主从；分布式 ID：雪花（时间戳+机器+序列）、号段 Leaf；分区表 vs 分库分表差异。脏读/不可重复读/幻读对应：读未提交/读已提交/可重复读/串行化——InnoDB 用 next-key lock（记录锁+间隙锁）在 RR 级防幻读。

### 1.5 ★ 计算题公式卡（送分必拿，5 年全部计算题）

| 公式 | 内容 | 真题应用 |
|------|------|----------|
| 死锁资源 | **R ≥ P×(N−1)+1** | 22-#12: 4×2+1=9；23-#12: 5×2+1=11；24-#5 / 25-#23: 5×1+1=6 |
| 奈奎斯特（无噪） | C=2W·log₂N | 21-#20: 2×4k×log₂16=32kbps；25-#14: 2×3k×5=30kbps |
| 香农（有噪） | C=W·log₂(1+S/N) | 22-#20: 30dB→S/N=1000→≈30kbps；dB=10lg(S/N) |
| 位示图 | 空闲块数/8=字节数 | 22-#44: 204800 块→25KB；25-#1: 4Mbit→512KB |
| 混合索引 | 直接+一级+二级 | 23-#44: 48KB+4MB+4GB；项/块=块大小/地址长 |
| 流水线 | T=(k+n−1)Δt；S 上限=k | 23-#59 |
| 可靠性/可用性 | 串联 R=∏Rᵢ；并联 R=1−∏(1−Rᵢ)；**可用性 A=MTTF/(MTTF+MTTR)**；MTBF=MTTF+MTTR | 25-#60: 0.9³=0.729；25-#65；24-#64 |
| Amdahl | 加速比=1/(串行比+(1−串行比)/并行数) | 22-#33 |
| McCabe | V(G)=E−N+2=判定节点+1=区域数，≤10 | 22-#68, 24-#13, m1-#69 |
| 线性规划 | 可行域顶点代入目标函数 | 21-#24=8；23-#24=11；24-#62=8 |
| 关键路径 | 最长路径定工期；总时差=LS−ES=LF−EF | 24-#60, 25-#59 |
| 概率/容斥 | 古典概率；容斥原理 | 24-#61=0.3；24-#2=243 |
| RM 调度界（案例） | U=ΣCi/Ti ≤ n(2^(1/n)−1)；n=3→0.779~0.799 | 25-案例三：U=0.708 可调度；EDF 只需 U≤1 |
| Cache 平均访问【拓展】 | T=命中率×Tc+(1−命中率)×(Tc+Tm) | 命中率 95%、Tc=1ns、Tm=100ns → 0.95×1+0.05×101=6ns |
| 磁盘访问时间【拓展】 | 访盘时间=寻道+旋转延迟+传输；旋转延迟=60/(2×转速) | 7200 转：60/7200/2≈4.17ms |
| 缺页/有效访问【拓展】 | EAT=(1−p)×内存访问+p×缺页处理 | p=缺页率；淘汰抖动=频繁缺页致 CPU 利用率骤降 |
| EVM 挣值【拓展】 | **CV=EV−AC，SV=EV−PV；CPI=EV/AC，SPI=EV/PV**（<1 超支/落后）；BAC/EAC=BAC/CPI | 高频陷阱：别把 CV 写成 EV−PV |
| EMV 期望货币值【拓展】 | EMV=Σ(概率×收益)，决策树选期望最大/损失最小 | 0.7×100+0.3×(−20)=64 |
| 盈亏平衡【拓展】 | BEP 销量=固定成本/(单价−单位变动成本) | 固 10 万、单价 500、变动 300 → 500 件 |
| 海明码校验位【拓展】 | 2^k ≥ n+k+1 | n=8 数据位 → k=4（16≥13） |
| 子网划分【拓展】 | 主机数=2^主机位−2；/26 块大小=64 | 192.168.1.0/26：64 个地址 62 台主机，4 个子网 |
| 码元/数据率【拓展】 | 数据率=波特率×log₂N（N=码元状态数） | 4 相调制 N=4，1200 波特→2400bps |

**【陷阱】** 可靠性 R(t)=e^(−t/MTTF)（概率），可用性 A=MTTF/(MTTF+MTTR)（时间占比）——两者常被混考。
**【陷阱】** 香农题先把 dB 换成功率比：30dB=10³；log₂1001≈10（因为 2¹⁰=1024），别硬算。

### 1.6 程序语言·多媒体·压缩补缺【拓展】（考纲内经典送分，近年少考更易冷门回归）

| 考点 | 核心结论 |
|------|----------|
| 表达式三表示 | 中缀→后缀（逆波兰式）按优先级加括号移运算符；后缀式用栈求值；表达式树：叶子=操作数、内部=运算符，前序遍历=前缀式、后序=后缀式 |
| 传值 vs 传引用 | 传值=拷贝副本，形参变不影响实参；传引用=传地址，影响实参；传名=宏展开式替换 |
| 绑定与作用域 | 静态绑定=编译时确定（重载）；动态绑定=运行时确定（多态/虚方法）；静态作用域按程序文本、动态作用域按调用链 |
| 自动机【拓展】 | 词法分析=有限自动机（DFA 每状态输入唯一转移、NFA 可多转移）；语法分析=下推自动机/递归下降 |
| 图像容量 | 位图存储=宽×高×位深/8 字节；256 色=8 位；800×600 256 色≈469KB；矢量图存绘制指令与分辨率无关 |
| 音频容量 | 存储=采样率×位深×声道数×时长/8；44.1kHz×16bit×2×60s≈10.3MB |
| 无损压缩 | **哈夫曼**：频率高码短、前缀码无歧义，平均码长=Σ(频率×码长)；行程编码 RLE；LZ77/LZW 字典法 |

## 四、下午案例·五大战场套路（每年结构固定）

### 4.1 试题一：质量属性识别 + 风格对比选型（15-25 分，分值在涨）

**属性映射口诀（★必背）**：
- 时间/吞吐/时限（"5 秒内""100ms"）→ **性能**
- 连续运行/故障切换/99.9%/RPO=0/RTO/重启 → **可用性**
- 加密/脱敏/权限/仅注册用户 → **安全性**
- 插件/配置化/不改代码/1 人周适配 → **可修改性**
- 日志/审计/追踪 → **可维护性 / 可测试性**（"日志定位故障"2025 考的是可测试性【陷阱】）
- 界面一致/快捷键/友好提示 → **易用性**
- 容错/校验/恢复 → **可靠性**

**风格四维对比模板（必背四行）**：交互方式 / 数据结构 / 控制结构 / 扩展方法。例：管道-过滤器（链式、数据流、数据流驱动、加过滤器）vs 数据仓储（星型辐射、集中共享、事件/调用驱动、模型适配）。

**风格轮换池**（历年：数据仓储 21/24、解释器 25、分层 23、批处理+事件驱动 22）：备齐**解释器三组件填空**（程序当前状态/解释器内部状态/解释器引擎）；黑板、事件驱动、微内核各准备一组对比。

**选型理由公式**：场景特征（共享数据多角色→仓储；规则多变→解释器；顺序流水→管道）× 风格特性，两句话收尾。

**【拓展】** 2026 备战：大模型平台/低代码引擎场景（解释器+插件微内核）；答题先抄题干数字进属性表（判卷踩点）。

### 4.2 试题二：UML + 设计模式（15 分）

- 用例图：参与者+include（必含）/extend（可选）+泛化。
- 类图：组合 vs 聚合看生命周期（Order-OrderItem=组合，实心菱形，24 真题）。
- 活动图：分支/并发（粗黑线）/泳道。
- 状态图五状态迁移条件逐一写；状态模式=各状态类内部 setState() 迁移，Context 不感知。
- 策略 vs 状态 vs 责任链辨析见 §2.3 拓展——**5 年 3 考策略/状态对比表**（意图/迁移控制方/场景三行）。
- 答题模板："Context 持有抽象引用（聚合）+ 具体实现列表 + 新增不改老代码（OCP）+ 依赖抽象（DIP）"。

**【拓展】** 2026 备战池：观察者（消息订阅场景）、命令模式（操作日志/撤销）、组合模式（组织架构树）。

### 4.3 试题三：嵌入式（15 分，必考）

- **AUTOSAR 分层**（22/24 真题）：MCAL→ECU 抽象层→BSW 服务层→**RTE**→ASW（SWC）；RTE 四作用=实现 VFB 虚拟功能总线/屏蔽硬件差异/可移植/任务映射调度；方法论 7 步背"系统配置→ECU 配置→SWC 设计→RTE 生成→任务映射→代码生成→集成测试"；复杂驱动层在 24 真题出现。
- **中断**（21）：优先级排定（定时器>串口>按键>看门狗兜底）；ISR 五要点（短小/清标志/置信号量/禁阻塞 API/临界区 volatile）；中断延迟=硬件响应+关中断区+上下文保存。
- **DMA+乒乓缓冲**（23）：CPU 只在帧边界介入；优先级反转→**优先级继承/天花板**两解法。
- **RM/EDF 计算**（25 新增）：U=ΣCi/Ti；RM 与周期成反比（静态），界 n(2^(1/n)−1)；EDF 截止期早优先（动态），U≤1 即可；硬实时 vs 软实时一句话。
- OTA A/B 分区（22）：写备用→校验 CRC/SHA→切 Bootloader→自检标记→失败回退。

**【拓展】** 备战池：CAN/CAN-FD 与 TSN 车载以太网；AUTOSAR Adaptive（AP，POSIX+服务化，面向自动驾驶）；看门狗喂狗机制；核间通信共享内存+mailbox。

### 4.4 试题四：数据库（15 分）

- **3NF 判定模板**（21/24 真题）："id→B→C 传递依赖 → 违反 3NF → 拆出依赖表 + 外键关联"。
- **反规范化**：优点减 JOIN 提性能；缺点冗余/更新异常/一致性成本；适用读多写少。
- **三级模式两级映像**（22/25）：对应独立性（§1.3 表）。
- **分库分表**（22/25）：垂直分库按业务域；水平 hash（均匀难扩容）/range（易扩容有热点）/一致性哈希（迁移少）；分片数取 2 的幂；雪花 ID/号段。
- **2PC**（25）：准备（锁定资源投票）→提交/回滚；四缺点=同步阻塞/协调者单点/部分提交不一致/性能差。
- **时序库**（23）：列式+LSM 高写+降采样+冷热分层（热 7 天 SSD→温 3 月磁盘→冷对象存储 Parquet）。
- **ES+Canal**（24）：多字段组合查询/like 优化；Canal 监听 Binlog 异步同步。
- **Redis 一致性**（21）：Cache-Aside 先更库再删缓存+短 TTL 兜底；【拓展】延迟双删/监听 Binlog 方案对比（m3 案例三）。

**【拓展】** 2026 备战池：NewSQL/TiDB（HTAP，TiFlash 列存副本）；分区表语法级 vs 分库分表中间件级；分布式事务选型题（支付不许超扣→TCC；通知最终一致→事务消息/本地消息表）；MVCC 解释快照读。

### 4.5 试题五：Web 架构 / 微服务 / 数据集成（15 分）

- **三层负载均衡**（25 真题）：接入层 DNS+LVS/F5 四层（IP+端口，百万并发）→网关层 Nginx/APISIX 七层（URL 路由/SSL 卸载/限流灰度）→服务层 Ribbon/Spring Cloud LB（实例列表）。
- **缓存三问**（25 真题+m1）：穿透（查不存在）=缓存空值+BloomFilter；击穿（热点 key 过期）=互斥锁 SETNX+逻辑过期；雪崩（同过期/宕机）=TTL 随机±10%+多级缓存（Caffeine）+集群 HA+限流降级。
- **HPA**（25）：期望副本数=ceil(当前副本×当前指标/目标指标)；缩容冷却 5 分钟防抖。
- **DDD 微服务拆分**（24）：事件风暴→限界上下文=服务边界；治理选型（Nacos/Gateway/Sentinel/SkyWalking/Seata）；绞杀者四步（基础设施→边缘服务→核心服务灰度+双写→旧系统下线）。
- **对比题模板库**：SOAP vs REST；ETL vs ELT；Lambda vs Kappa；联邦查询 vs 数仓 vs 湖仓；限流三算法（令牌桶可突发/漏桶整流/滑动窗口临界突刺）。
- **消息可靠性**：生产确认+持久化+手动 ACK+死信；顺序=同 Key 同分区。

**【拓展】** 2026 备战池：AI 推理网关（大模型高并发：请求排队+批量 batching+GPU 亲和）；WebSocket 长连接接入层；四层 vs 七层 LB 细节对照；Service Mesh 灰度（Istio 按权重路由 95/5）。

## 六、易混淆对比清单（考前最后过一遍）

| 对比对 | 一句话区分 |
|--------|-----------|
| 敏感点 vs 权衡点 | 影响 1 个属性 vs 影响**多个**属性 |

| 2NF/3NF/BCNF | 部分依赖 / 传递依赖 / 决定因素皆候选键 |
| 页式 vs 段式 | 内碎片消外碎片 / 便于共享有外碎片 |
| 死锁预防 vs 避免 | 破坏四条件（互斥不可破） vs 银行家安全序列 |
| 可靠性 R(t) vs 可用性 A | e^(−t/MTTF) vs MTTF/(MTTF+MTTR) |
| FIFO vs LRU/OPT | Belady 异常只有 FIFO |
| SAAM/ATAM/ARID/CBAM | 场景可修改性 / 权衡 / 早期局部 / 成本收益 |
| 架构风格 vs 开发模型 | 瀑布是模型不是风格 |
| 断路器三态 | 关闭/打开/半打开（无"熔断态"这个说法） |
| CAP 的 P | 分区容错（不是持久性） |
| 穿透 vs 击穿 vs 雪崩 | 不存在 key / 单热点过期 / 大批同失效或宕机 |
| 令牌桶 vs 漏桶 | 可突发 vs 恒速整流 |
| ETL vs ELT | 先转换再装 vs 先入湖再转换 |
| Lambda vs Kappa | 批+速双链路 vs 纯流重放 |
| SOAP vs REST | 协议 WS-*重 vs 风格 HTTP+JSON 轻 |
| 聚簇 vs 非聚簇索引 | 叶存数据行 vs 叶存主键（回表） |
| 组合 vs 聚合 | 生命周期一致实心菱形 vs 可独立空心 |
| CPA 混淆项 | 正向跟踪=需求→制品（别被题干带反） |
| 脏读 vs 不可重复读 vs 幻读 | 读到未提交 / 两次读同行被改 / 两次读多出/少行（需串行化或间隙锁） |
| 2PC vs TCC vs Saga | 资源锁定强一致阻塞 / 业务预留三阶段 / 长事务补偿最终一致 |
| Raft vs Paxos vs PBFT | 崩溃故障易理解 Leader / 多数派鼻祖 / **拜占庭**恶意节点 |
| CP 注册中心 vs AP | Zookeeper(CP) vs Eureka/Nacos(AP) |
| 垂直分库 vs 水平分表 | 按业务/列拆 vs 按行（哈希/范围）拆 |
| Cache Aside vs Write Through vs Write Behind | 先更库后删缓存 / 同步双写 / 异步刷盘（可能丢） |
| 蓝绿 vs 金丝雀 vs 滚动 | 两套环境全切 / 小比例渐放量 / 逐步替换 |
| 限流 vs 熔断 vs 降级 | 入口控速 / 故障时快速失败 / 舍弃非核心保核心 |
| IDS vs IPS | 旁路只告警 vs 串接可阻断 |
| 对称 vs 非对称 | 单钥快(AES/SM4) / 双钥慢(RSA/SM2)；签名用私钥 |
| 数字签名 vs 数字信封 | 私钥签摘要(防抵赖) / 对称钥加密数据+非对称传密钥 |
| 散列 vs 加密 | 不可逆(MD5/SM3) vs 可逆 |
| 批处理 vs 管道-过滤器 | 整体阶段间传完整数据 vs 流式增量传递 |
| 事件驱动 vs 管道-过滤器 | 消息发布订阅松耦合 vs 数据流直连 |
| 包含 include vs 扩展 extend | 用例必发生（基例→包含）vs 条件可选（扩展→基例） |
| RM vs EDF | 周期短优先(静态) vs 截止早优先(动态) |
| 优先级继承 vs 天花板 | 持锁者升到请求者优先级 vs 一拿锁就升到预设最高 |
| RPO vs RTO | 允许丢多少数据 vs 允许停多久 |
| SaaS vs PaaS vs IaaS | 买应用 / 买平台运行时 / 买机器资源 |
| Docker 容器 vs 虚拟机 | 共享内核进程级隔离秒起 / 独立 Hypervisor 内核分钟起 |

## 七、2026 拓展知识储备（真题没考、大概率要来）【拓展】

1. **大模型应用架构**：RAG 流水线（文档切分→Embedding→向量检索→重排→生成）；多模型路由网关；Token 限流与成本治理；模型即服务 MaaS。——2025 三科已铺垫，2026 大概率升级为案例/论文主角。
2. **零信任安全**：SDP+IAM+持续验证；替代边界防火墙思维；与纵深防御结合写论文安全题。
3. **单元化/异地多活**：Set 化部署、数据同步 DTS、流量切流 DNS/网关双控；RPO=0/RTO 分钟级——高可用论文亮点。
4. **数据网格 Data Mesh**：领域自助数据产品+联邦治理；对"数据集成"论文是差异化素材。
5. **混沌工程**：故障注入演练（ChaosBlade/Chaos Mesh）；稳态假设→实验→度量——可靠性论文加分。
6. **WebAssembly**：沙箱可移植运行时；边缘函数新载体。
7. **绿色计算/FinOps**：成本可视化、按需弹性——Serverless 论文收尾可用。
8. **车联网/软件定义汽车**：SOA 车载、OTA 全链路——嵌入式案例延伸。
9. **向量数据库 + RAG 工程**：Embedding 模型选型、混合检索（向量+关键词 BM25）、重排 rerank、上下文窗口管理、引用溯源防幻觉——2026 案例最可能的新场景。
10. **AI Agent 架构**：规划(Planning)+记忆(短期上下文/长期向量库)+工具调用(Function Calling)+多智能体协作；可观测与成本（Token 计费）是新治理点。
11. **国产化/信创替代**：达梦/openGauss/麒麟适配论文："安全可控+平滑迁移（双轨运行+语法兼容层+数据校验）"。
12. **低代码/AI 生成式开发**：元数据驱动+解释器/规则引擎风格的现实落地，对应案例试题一解释器考点。

## 八、考场应考策略（三科时间分配 + 踩点法）【实战】

### 8.1 上午综合（75 题 / 150 分钟，及格 45）

- **时间**：约 2 分钟/题；前 60 题 110 分钟，英语 10 题 20 分钟，留 20 分钟检查+涂卡（机考为勾选）。
- **答题顺序**：先做确定的；计算题（死锁/奈奎斯特/关键路径/可靠度）标记后立刻套公式卡；英语题最后做（题干长但词汇简单）。
- **蒙题纪律**：不空题；排除 2 个后 50% 概率选；含"一切/必须/所有"绝对化表述多为错；**答案卡与解析冲突时以解析知识为准**（5 年回忆版错位多）。
- 英语题技巧：先看选项词性/搭配回填，完形靠逻辑词（however/therefore/moreover）。

### 8.2 下午案例（5 大题 / 90 分钟，及格 45）

- **时间分配**：试题一 20 分钟（含填表），二~五各 15 分钟，留 10 分钟补空。
- **通用踩点法**：
  1. 填空题：术语写教材标准词（如"星型""模型适配"），不写口语；
  2. 简答题按"名词解释 + 分点机制（3-5 条）+ 结合题干一句"三段写；
  3. 对比题永远画表（维度 vs A vs B），四维模板（交互/数据/控制/扩展）直接套；
  4. 计算题写公式再代数，过程分 > 结果分；
  5. 不确定的多写：案例不倒扣，关键词覆盖即给分。
- 五年固定套路已在 §四；**试题一属性映射**先做（送分），架构图填空最后做。

### 8.3 下午论文（4 选 1 / 120 分钟 / 2500 字，及格 45）

| 时段 | 任务 |
|------|------|
| 0-10 min | 选题（选案例库素材最熟的，不选最新潮的）+ 列提纲（3 个分论点+对应数字） |
| 10-25 min | 写摘要 300 字（四句式，先写后誊或边写边定） |
| 25-105 min | 正文：项目概述 300 → 理论 700 → 实践三段各 500（方案+挑战+对策+数字）→ 结尾 100 |
| 105-120 min | 检查：题眼是否全覆盖、字数、错别字、首尾呼应摘要 |

- **救命原则**：写不完 > 写得精——结构完整（摘要+三段+结尾）是 45 分的底线；
- 挑战必须与对策一一对应，每个分论点结尾砸数字（从 §5.2 论据卡取）；
- 项目角色统一写"系统架构师/技术负责人"，项目名称、规模、时间前后一致（防判卷穿帮）；
- 字迹（机考为打字，注意排版分段，每段别超 5 行）。

### 8.4 考前 7 天清单

1. 只看：本文档 §〇 频率表 + §1.5 公式卡 + §六 混淆清单 + 4 张 cheatsheet；
2. mock-02/03 各做一次完整限时三科，校准时间；
3. 论文模板 5 篇各默写一遍提纲+摘要；
4. 准备：准考证、身份证、路线；机考环境提前确认（输入法/键盘/不能带资料）；
5. 睡眠优先，最后一天不背新东西。
