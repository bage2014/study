## 1. ★ 挣值管理 EVM（最高频，几乎年年考）

### 1.1 三个基本值
| 缩写 | 全称 | 含义 |
|------|------|------|
| **PV** | Planned Value 计划值 | 到检查点，计划完成工作的预算（计划花多少） |
| **EV** | Earned Value 挣值 | 实际完成工作按预算标准值多少钱（实际干了多少活，按预算算） |
| **AC** | Actual Cost 实际成本 | 实际花了多少 |

### 1.2 四个评价指标（★ 背公式）
| 指标 | 公式 | >0 / >1 含义 |
|------|------|--------------|
| 成本偏差 CV | **CV = EV − AC** | 正 = 省钱 |
| 进度偏差 SV | **SV = EV − PV** | 正 = 超前 |
| 成本绩效指数 CPI | **CPI = EV / AC** | >1 成本节约 |
| 进度绩效指数 SPI | **SPI = EV / PV** | >1 进度提前 |

记忆：**差值用 EV 开头减，指数用 EV 开头除**；EV 永远是分子/被减数。

### 1.3 完工预测
- **BAC**：完工总预算（Budget At Completion）
- **典型偏差（默认，偏差会持续）**：
  - EAC = BAC / CPI
  - ETC = EAC − AC = (BAC − EV) / CPI
- **非典型偏差（以后按原计划，偏差是特例）**：
  - ETC = BAC − EV
  - EAC = AC + ETC
- VAC = BAC − EAC（完工偏差，正 = 预计省钱）

### 1.4 例题
> 某项目 BAC=100 万，检查点：PV=40 万，EV=30 万，AC=50 万。
> CV = 30−50 = **−20 万（超支）**；SV = 30−40 = **−10 万（滞后）**
> CPI = 30/50 = **0.6**；SPI = 30/40 = **0.75**
> 典型 EAC = 100/0.6 ≈ **166.7 万**；ETC = 166.7−50 = **116.7 万**

## 2. ★ 进度网络与关键路径（高频）

### 2.1 六标时计算（正推 + 逆推）
```
正推（从左到右，取大值）：
  EF = ES + 工期；ES = 所有紧前 EF 的最大值
逆推（从右到左，取小值）：
  LS = LF − 工期；LF = 所有紧后 LS 的最小值
```
- **总时差（总浮动）TF = LS − ES = LF − EF**
- **自由时差 FF = 紧后 ES 的最小值 − 本活动 EF**
- **关键路径**：总时差 = 0 的活动连成的路径；= 网络中最长路径，决定最短工期
- 关键路径可能有多条；压缩工期要压关键活动，且可能让关键路径转移

### 2.2 三点估算 PERT（计划评审技术）
- 期望工期：**t = (O + 4M + P) / 6**（O 乐观、M 最可能、P 悲观）
- 标准差：**σ = (P − O) / 6**
- 方差：**σ² = ((P − O)/6)²**；路径上多个活动方差可相加（标准差不能直接加）
- 概率：±1σ = 68.27%，±2σ = 95.45%，±3σ = 99.73%

### 2.3 工期压缩
- 赶工 Crashing：加资源换时间，选**关键路径上单位赶工成本最低**的活动
- 快速跟进 Fast Tracking：把串行活动并行，增加返工风险

### 2.4 例题
> A(3) → B(5) → D(2)；A → C(4) → D。
> 路径 ABD = 10，路径 ACD = 9 → **关键路径 ABD，工期 10**
> C 的总时差 = 10 − 9 = 1（C 可晚 1 天不影响总工期）

## 3. 经济学计算

### 3.1 ★ 盈亏平衡点 BEP
```
保本产量 Q = 固定成本 F / (单价 P − 单位变动成本 V)
保本销售额 = F / (1 − 变动成本率)
```
- 利润 = (P − V) × Q − F；利润为 0 时即盈亏平衡
- 经营安全边际 = (实际销量 − 保本销量) / 实际销量，>30% 安全

### 3.2 货币时间价值
- 终值 F = P(1+i)ⁿ；现值 P = F/(1+i)ⁿ
- **净现值 NPV** = 各年净现金流折现之和；**NPV ≥ 0 项目可行**；多方案选 NPV 大的
- 内部收益率 IRR：使 NPV = 0 的折现率，IRR > 基准收益率则可行

### 3.3 ★ 决策树与 EMV 期望货币值
- EMV = Σ（概率 × 损益值）
- 决策点（方框 □）取各方案 EMV **最大值**；机会点（圆圈 ○）算期望
- 例：方案 A 成功 0.7 赚 100 万/失败 0.3 亏 20 万 → EMV = 0.7×100 + 0.3×(−20) = **64 万**

### 3.4 其他常考小公式
- **沟通渠道数 = n(n−1)/2**（n 人全员沟通；增加 1 人增加 n 条）
- 投资回收期 = 累计净现金流转正的年份（静态）；动态需折现
- 投资回报率 ROI = 年平均利润 / 总投资 × 100%
- 自制/外购分析、加权评分法（Σ 权重×得分，选总分高）

## 4. 运筹学方法（每年 2-4 题，会认会算基础题）

### 4.1 线性规划
- 目标函数线性 + 约束线性；最优解一定在**可行域顶点**
- 图解法：画出约束直线围成的可行域 → 顶点逐一代入目标函数比较
- 两个变量用图解；复杂题可直接用选项代入验证

### 4.2 图论（考概念 + 简单计算）
| 问题 | 算法 | 要点 |
|------|------|------|
| 最小生成树 | **Prim**（从点扩展）、**Kruskal**（边排序逐条选，不形成环） | n 个点选 n−1 条边，总权最小 |
| 最短路径 | **Dijkstra**（单源，非负权）、Floyd（全源） | 逐步松弛更新距离 |
| 最大流量 | 福特-富尔克森标号法 | **最大流 = 最小割**容量 |
| 关键路径 | CPM/PERT | 最长路径 |
| 网络计划优化 | 工期-成本优化 | 压关键活动 |

### 4.3 其他模型（认题即可）
- **运输问题**：产销平衡下总运费最小，表上作业法（西北角法/最小元素法给初解，位势法检验，闭回路调整）
- **指派问题**：n 人 n 活一一配对总耗时最小，**匈牙利法**
- **动态规划**：分阶段决策，最优化原理（贝尔曼），如背包、最短路径
- **排队论**：M/M/1 模型；利用率 ρ = λ/μ（到达率/服务率）；λ ≥ μ 队列无限增长
- **预测**：移动平均、指数平滑（本期预测 = 上期实际×α + 上期预测×(1−α)）
- **博弈论**：零和博弈、最大最小（鞍点）、纳什均衡
- **状态转移/马尔可夫**：转移概率矩阵行和为 1
- **数学规划**：整数规划、非线性规划；灵敏度分析

### 4.4 运筹题蒙题策略
- 每年 5 题左右通常有 2-3 题简单（代入/基础公式），优先拿下
- 复杂运输/动态规划题**不纠缠**，标记后跳过，最后统一蒙，保证时间给架构题

## 5. 项目管理知识体系（概念题）

### 5.1 十大知识领域（PMBOK）
整合、范围、进度、成本、质量、资源、沟通、风险、采购、**干系人**

### 5.2 风险管理
- 过程：识别 → 定性分析 → 定量分析 → 规划应对 → 监控
- **风险暴露 RE = 风险发生概率 P × 损失 L**
- 应对策略：
  - 威胁：规避 / 转移（保险、外包）/ 减轻 / 接受
  - 机会：开拓 / 分享 / 提高 / 接受
- 定性风险分析工具：概率影响矩阵（P-I Matrix）

### 5.3 质量管理
- 规划质量 → 管理质量（过程）→ 控制质量（结果）
- **质量成本 COQ**：
  - 一致性成本：预防（培训、流程）+ 评价（测试、审查）
  - 非一致性成本：内部失败（返工、废品）+ 外部失败（保修、客诉、声誉）
- **老七工具**：因果图（鱼骨/石川）、流程图、核查表、帕累托图（80/20 排序）、直方图、控制图、散点图
  - 控制图：上下控制限 ±3σ，七点规则（连续 7 点同侧 = 失控）
  - 帕累托：抓主要缺陷，区分"关键少数与次要多数"
- 新七工具：亲和图、过程决策程序图、关联图、树形图、优先矩阵图、活动网络图、矩阵图

### 5.5 合同与招投标（考数字）
| 合同类型 | 特点 | 卖方风险 |
|----------|------|----------|
| 固定总价 FFP | 一口价 | 高（成本超支卖方担） |
| 总价+激励 FPIF | 有绩效奖励 | 中 |
| 成本补偿 CPFF | 实报实销+固定费 | 低（买方担） |
| 工料合同 T&M | 按工时单价，紧急小额 | 中 |

招投标法常考数字：
- 招标文件发售至提交投标文件**不少于 20 日**
- 评标结果公示期 **3 日**；对招标文件异议在截止 **10 日前**提出
- 中标通知书发出后 **30 日内**签合同
- 投标保证金不超过项目估算价 **2%**
- 不得少于 **3 家**投标人；少于 3 家应重新招标
- 监理：信息系统工程实行第三方监理，"四控三管一协调"（投资/进度/质量/变更控制，安全/合同/信息管理 + 协调）
