# 03 软件架构核心

> 高频核心，必背必默写
> 占比：上午 20-25%，案例几乎必考，论文核心素材

## 1. 架构定义

> 软件架构 = {构件, 连接件, 约束}
> 系统的高层结构，包括软件元素、元素间关系、元素属性、约束

## 2. 4+1 视图模型（Kruchten）

## 4. ★ 14 种架构风格（必背）

### 4.1 数据流风格
1. **批处理**：整批传递，顺序执行
2. **管道-过滤器**：流式处理，松耦合；UNIX shell、编译器

### 4.2 调用/返回风格
3. **主程序-子程序**：层次化分解
4. **面向对象**：封装继承多态
5. **层次结构**：每层只依赖下层；OSI、TCP/IP

### 4.3 独立组件风格
6. **进程通信**：独立进程间消息
7. **事件驱动（隐式调用）**：解耦；GUI、消息总线、Reactor

### 4.4 虚拟机风格
8. **解释器**：解释执行规则；JVM、SQL 引擎、规则引擎
9. **基于规则系统**：知识库 + 推理机；专家系统

### 4.5 仓库风格
10. **数据库系统**：中心数据 + 多访问者
11. **超文本系统**：网状链接；Wiki

### 4.6 其他重要风格
12. **客户端/服务器（C/S）**：两层/三层
13. **浏览器/服务器（B/S）**：瘦客户端
14. **MVC / MVP / MVVM**：
    - MVC：Model-View-Controller，控制器中转
    - MVP：Presenter 处理逻辑
    - MVVM：ViewModel 双向绑定

### 补充（虽不在 14 但常考）
- **黑板架构**：知识源 + 黑板 + 控制；语音识别
- **REST**：资源 + 统一接口 + 无状态
- **微服务**：独立部署、轻量通信、去中心化
- **富互联网应用 RIA**：Ajax / Flex / Silverlight

## 5. ★ 6 大质量属性 + 战术（必背）

### 5.1 运行期
| 属性 | 含义 | 关键战术 |
|------|------|----------|
| 性能 | 处理请求的时间/吞吐 | 缓存 / 并发 / 资源调度 / 算法优化 |
| 可用性 | 系统正常运行比例 | 心跳 / 冗余 / 故障转移 / 重启 |
| 安全性 | 抗攻击 / 授权 / 机密性 | 认证 / 授权 / 加密 / 审计 / 隔离 |
| 易用性 | 用户使用难易 | 撤销 / 在线帮助 / 向导 / 一致性 |

### 5.2 开发期
| 属性 | 含义 | 关键战术 |
|------|------|----------|
| 可修改性 | 修改的难易/成本 | 限制修改范围 / 接口-实现分离 / 配置化 |
| 可测试性 | 通过测试发现缺陷 | 录像回放 / 接口实现分离 / 内置监控 |

### 5.3 质量属性场景六要素（必背）
1. **刺激源** Source
2. **刺激** Stimulus
3. **制品** Artifact（受刺激的部分）
4. **环境** Environment
5. **响应** Response
6. **响应度量** Response Measure

## 7. ★ 架构评估方法（必考）

### 7.1 评估方式
- 基于调查问卷 / 基于场景 / 基于度量

### 7.2 基于场景的三大方法
| 方法 | 全称 | 特点 | 步骤数 |
|------|------|------|--------|
| SAAM | Software Architecture Analysis Method | 最早，关注可修改性 | 6 步 |
| ATAM | Architecture Trade-off Analysis Method | 多质量属性 + 权衡 | 9 步 |
| ARID | Active Reviews for Intermediate Designs | 部分设计评估 | - |

### 7.3 ATAM 九步
1. ATAM 方法呈现
2. 商业动机呈现
3. 架构呈现
4. 架构方法识别
5. **效用树生成**（关键：根-属性-细化-场景-重要性/难易度）
6. 分析架构方法
7. 讨论分级 + 场景
8. 第二轮分析架构方法
9. 结果呈现

### 7.4 SAAM 六步
1. 形成场景
2. 描述架构
3. 分类场景（直接 / 间接）
4. 评估场景
5. 风险暴露评估
6. 评估结果

## 8. 构件与中间件

### 8.1 构件标准
- CORBA（OMG）：ORB + IIOP + IDL
- EJB（Sun/Oracle）：会话/实体/消息 Bean
- COM+/DCOM（Microsoft）

### 8.2 中间件分类
- 数据库访问中间件：ODBC / JDBC
- 远程过程调用：RPC
- 面向消息：MOM（MQ、Kafka）
- 分布式对象：CORBA / EJB / DCOM
- 事务处理：TP Monitor（Tuxedo）
- Web 应用服务器：Tomcat / WebLogic
- 其他：嵌入式 / 安全 / 门户
