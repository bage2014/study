# rca-agent 项目规范化变更

- **日期**：2026-10-18
- **类型**：工程规范 / 项目结构
- **影响范围**：仓库根目录（不含业务代码）
- **依据**：`common-project-standard` 技能第 6、10 节规范要求

## 变更背景

按 `common-project-standard` 技能第 10 节「代码审查检查清单」审计，当前项目多项规范文件缺失：根 `.gitignore` 未配置导致 `target/`、`*.class` 等产物未被忽略；缺少 `SKILLS.md`、`.traeignore`、各 AI 工具 ignore 文件、`skills/` 目录与 `.trae/config.yml`。本次变更一次性补齐。

## 变更内容

### 新增文件

| 文件 | 用途 |
|------|------|
| `.gitignore` | 根级 Git 忽略规则：构建产物、IDE、日志、配置/敏感文件、前端依赖、H2 数据文件、AI 缓存、OS 文件 |
| `.traeignore` | Trae 技能系统忽略：技能缓存、索引、测试产物、编辑器文件、依赖、构建产物 |
| `.cursorignore` | Cursor AI 忽略规则 |
| `.codeiumignore` | Codeium AI 忽略规则（二进制/大文件为主） |
| `.aiderignore` | Aider AI 忽略规则 |
| `.copilotignore` | GitHub Copilot 忽略规则（含敏感文件） |
| `SKILLS.md` | 技能清单：个人定制 / 通用 / 开源包装 三类注册 |
| `skills/README.md` | 项目技能目录说明：结构、命名、注册流程 |
| `.trae/config.yml` | 技能系统配置：auto-load、路径、启用清单、项目模块 |

### 修改文件

| 文件 | 变更 |
|------|------|
| `rca-agent-web/.gitignore` | 补 `.env`、`.env.local`、`.env.*.local`、`test-results/`、`playwright-report/` |

### 删除项

### 已存在文件（未动）

## 影响与风险

- **构建**：无影响。本次仅新增/修改忽略规则与规范文档。
- **Git 历史**：首次添加 `.gitignore` 后，`target/` 等历史已追踪文件若需清理，可执行 `git rm -r --cached target/`，本次变更不主动处理。
- **协作**：团队其他成员拉取后自动生效，无需额外操作。

## 后续建议

1. 如需本地脚本验证技能规范性，可按 `common-project-standard` 第 8 节创建 `validate-skills.sh`。
2. 新增项目级技能时，同步更新 `SKILLS.md` + `AGENTS.md` 第 3 节 + `.trae/config.yml` 的 `enabled` 列表。
3. 项目切换生产 MySQL 时，记得在 `.gitignore` 中补 `application-prod.yml` 等敏感文件规则。
