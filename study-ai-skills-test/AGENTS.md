# AGENTS.md — AI 编码助手规范

本文件定义 AI 在本项目中应遵循的约定。

## 项目概述

- 项目名称：study-ai-skills-test
- 目标：验证当前会话可用的全部技能（Skill）能否被真实触发调用
- 验证方式：**提示词驱动**——每个技能一个独立提示词文件，人工拷贝到 TRAE 对话窗口执行，观察技能是否触发并输出执行响应（不使用测试脚本）

## 目录结构

```
study-ai-skills-test/
├── AGENTS.md                 # 本文件
└── prompts/
    ├── README.md             # 提示词索引（按分类列出全部技能）
    └── <skill-id>.md         # 每个技能一个独立验证提示词
```

## 提示词使用流程

1. 打开 `prompts/<skill-id>.md`，将「提示词」段落整段复制到 TRAE 对话窗口发送
2. 观察回复：是否出现技能加载信息（Skill Path）、埋点命令是否执行、是否输出技能执行响应
3. 硬证据核对：`tail -n 1 ~/.trae-cn/skill-usage.jsonl` 应出现该技能的调用记录
4. 将结果回填到该文件底部「执行响应记录」段

## 编写约定

- 新增技能验证：在 `prompts/` 下新建 `<skill-id>.md`，并同步更新 `prompts/README.md` 索引
- 提示词必须包含：明确点名技能、一个该技能领域的最小可观察任务、埋点命令执行要求、「技能执行响应」输出要求
- 每个技能独立一个文件，禁止合并多个技能到一个提示词
- 验证点用 checkbox 列出，便于人工逐项勾选

## 文档约定

- 提示词索引：`prompts/README.md`
- 不主动创建其他文档，除非用户明确要求
