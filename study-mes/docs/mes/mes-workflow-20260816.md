# MES 业务流程

> 创建时间：2026-08-16
> 模块：MES

梳理 MES 常见核心业务流程，含状态流转、关键节点、异常处理。

## 一、生产工单全流程

### 状态机

```
[已创建] → [已下达] → [已派工] → [执行中] → [已完工] → [已关闭]
              ↓            ↓          ↓
          [已暂停] ← ────┘          [已终止]
```

### 关键节点

| 节点 | 动作 | 输入 | 输出 |
|------|------|------|------|
| 工单创建 | ERP 同步或手工创建 | 销售订单/计划 | 工单 |
| 工单下达 | 校验齐套、工艺 | 工单、BOM、工艺 | 派工单 |
| 派工 | 分配人员、设备 | 派工单 | 工序任务 |
| 报工 | 工序完工录入 | 合格/不合格数 | WIP 更新 |
| 完工 | 全工序完成 | 报工数据 | 入库单 |
| 关闭 | 结算、归档 | 工单数据 | 历史档案 |

## 二、报工流程（关键子流程）

```
1. 扫码工单/工序
2. 校验：人员资质、设备状态、物料批次
3. 录入：合格数、不合格数、不良代码
4. 采集：设备参数、加工时间
5. 自动：更新 WIP、生成质量记录、触发流转
6. 异常：不合格品隔离，触发返工单
```

## 三、质量检验流程

### IPQC 巡检流程

```
1. 检验计划触发巡检任务
2. 抽样（AQL/全检）
3. 录入检验数据
4. 判定：合格 / 不合格 / 让步接收
5. 不合格 → 隔离 → 评审 → 返工/报废/降级
6. SPC 自动更新控制图
```

### 不良品处理

```
发现不良 → 隔离（红牌） → 评审 → 决策
                                  ├─ 返工（生成返工工单）
                                  ├─ 返修
                                  ├─ 降级
                                  └─ 报废
```

## 四、设备管理流程

### 故障处理

```
1. 设备停机（自动/手工报修）
2. 派单维修
3. 维修记录（故障代码、原因、措施）
4. 验证恢复
5. 统计 MTBF / MTTR
```

### 保养流程

```
保养计划 → 触发任务 → 执行点检 → 异常上报 → 关闭
```

## 五、物料齐套与配料

```
1. 工单下达触发配料需求
2. 系统校验线边库存 + 在途
3. 缺料 → 触发补料/领料
4. 齐套 → 配料单 → AGV/人工配送
5. 工位扫码接收
```

## 六、追溯查询流程

### 正向追溯（物料 → 成品）

```
输入：物料批次号
→ 查询用于哪些工单
→ 关联成品序列号/批次
→ 关联发货记录
→ 客户
```

### 反向追溯（成品 → 物料）

```
输入：成品序列号/批次
→ 查询工单
→ 解析 BOM 用料
→ 查询每物料批次
→ 供应商批次
```

## 七、常用业务规则

| 规则 | 说明 |
|------|------|
| 不允许超工单报工 | 报工数 ≤ 工单数 + 容差 |
| 强制首检 | 关键工序首件必须检验通过 |
| 批次先进先出 | FIFO 投料 |
| 不合格品禁止流转 | 隔离状态锁定 |
| 工艺版本生效 | 按工单下达时点锁定工艺版本 |

## 八、异常处理速查

| 异常 | 处理 |
|------|------|
| 齐套失败 | 触发缺料预警，暂停下达 |
| 工艺参数超标 | 设备报警，工序暂停，QC 评审 |
| 设备故障 | 自动派维修单，工单暂停或转机 |
| 物料批次错 | 防呆拦截，禁止报工 |
| 人员无资质 | 派工校验失败，禁止上岗 |
