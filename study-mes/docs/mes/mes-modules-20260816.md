# MES 核心模块

> 创建时间：2026-08-16
> 模块：MES

依据 ISA-95 标准与行业实践，MES 核心功能模块梳理如下。

## 一、模块全景图

```
┌─────────────────────────────────────────────────────────┐
│                          MES                            │
├──────────────┬──────────────┬──────────────┬────────────┤
│  生产管理    │   质量管理    │   设备管理    │  库存管理   │
├──────────────┼──────────────┼──────────────┼────────────┤
│  工艺管理    │   人员管理    │   追溯管理    │  看板/报表  │
└──────────────┴──────────────┴──────────────┴────────────┘
```

## 二、各模块说明

### 1. 生产管理（Production Management）

| 能力 | 说明 |
|------|------|
| 工单管理 | 工单下达、派工、暂停、关闭 |
| 工序调度 | 工序排队、优先级、资源分配 |
| 报工管理 | 工序完工报工、合格/不合格数量 |
| 在制品管理 | WIP 状态、流转卡、批次跟踪 |
| 生产排程 | 短期排产、甘特图、产能均衡 |

### 2. 质量管理（Quality Management）

| 能力 | 说明 |
|------|------|
| 检验计划 | IQC/IPQC/OQC 检验项配置 |
| 检验执行 | 首检、巡检、末检、抽检 |
| 不良管理 | 不良代码、不良品隔离、返工 |
| SPC | 统计过程控制、控制图、CPK |
| 质量追溯 | 按批次/序列号正反向追溯 |

### 3. 设备管理（Equipment Management）

| 能力 | 说明 |
|------|------|
| 设备台账 | 设备基础信息、BOM |
| 状态采集 | 运行/停机/故障状态实时采集 |
| OEE 分析 | 可用率、性能、质量率统计 |
| 点检保养 | 日点检、定期保养计划 |
| 故障管理 | 故障报修、维修记录、MTBF/MTTR |

### 4. 库存管理（Inventory Management）

车间级线边仓管理，区别于 WMS 的全厂仓储。

| 能力 | 说明 |
|------|------|
| 线边库存 | 工位物料库存 |
| 批次/序列号 | 物料批次追溯 |
| 配料齐套 | 工单用料齐套检查 |
| 入库/领用 | 车间内物料流转 |
| 盘点 | 周期性盘点 |

### 5. 工艺管理（Process/BOP Management）

| 能力 | 说明 |
|------|------|
| 工艺路线 | Routing 工序定义 |
| 工艺参数 | 每工序的参数标准 |
| BOP | Bill of Process，与 BOM 关联 |
| 工艺版本 | 版本控制与生效范围 |
| 工艺下发 | 工艺参数下发到设备 |

### 6. 人员管理（Personnel Management）

| 能力 | 说明 |
|------|------|
| 资质管理 | 操作工技能矩阵、资质证书 |
| 派工 | 按资质分配工位 |
| 工时 | 出勤、工时统计 |
| 绩效 | 计件/计时绩效 |

### 7. 追溯管理（Traceability）

| 能力 | 说明 |
|------|------|
| 正向追溯 | 物料 → 成品 → 客户 |
| 反向追溯 | 成品 → 物料批次 → 供应商 |
| 族谱 | 产品族谱关系（Genealogy） |
| 工艺追溯 | 加工参数、设备、操作员 |

### 8. 看板与报表（Dashboard & Reporting）

| 能力 | 说明 |
|------|------|
| 实时看板 | 生产进度、设备状态、质量异常 |
| 报表 | 工单完成率、OEE、不良率 |
| 报警 | 异常实时推送 |

## 三、模块间关系

- 生产管理驱动：工单 → 工艺 → 报工 → 追溯。
- 质量贯穿全流程：进料 → 过程 → 成品。
- 设备/人员为资源约束。
- 库存为物料载体。
- 追溯为数据汇总层。
