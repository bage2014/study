# MES 制造执行系统 - 概述

> 创建时间：2026-08-16
> 模块：MES（Manufacturing Execution System）

## 一、定义

MES（Manufacturing Execution System，制造执行系统）是面向车间层的生产信息化管理系统。

- 上承 ERP（企业资源计划）：接收计划、订单。
- 下接设备/产线：下发指令、采集数据。
- 定位：计划与执行之间的"桥梁层"。

## 二、核心定位

| 层级 | 系统 | 关注点 |
|------|------|--------|
| 计划层 | ERP | 订单、成本、资源规划（天/周） |
| 执行层 | MES | 生产执行、过程管控（小时/分钟） |
| 控制层 | SCADA/PLC | 设备控制、实时采集（秒/毫秒） |

MES 处于"承上启下"的关键位置，负责将 ERP 的计划落地为可执行的车间作业，并将执行结果反馈给上层。

## 三、核心价值

1. **透明化**：实时掌握车间进度、设备状态、在制品情况。
2. **可追溯**：人、机、料、法、环、测（5M1E）全记录，支持正反向追溯。
3. **防错防呆**：工序校验、物料校验、工艺参数校验，减少人为失误。
4. **效率提升**：减少纸质流转、缩短换线时间、提升设备 OEE。
5. **质量闭环**：质量数据自动采集，异常自动报警与隔离。

## 四、典型适用行业

- 离散制造：电子、机械、汽车零部件、装备制造。
- 流程制造：食品、化工、制药、冶金。
- 半导体 / 新能源：晶圆、电池、光伏（对追溯要求极高）。

## 五、关键术语

| 术语 | 说明 |
|------|------|
| Work Order | 工单，生产指令载体 |
| Routing | 工艺路线，工序序列 |
| BOP | Bill of Process，工艺清单 |
| OEE | 设备综合效率（可用率 × 性能 × 质量率） |
| WIP | Work In Process，在制品 |
| SFC | Shop Floor Control，车间控制 |
| Genealogy | 族谱追溯，产品族谱关系 |
