# PLM 产品生命周期管理 - 概述

> 创建时间：2026-08-16
> 模块：PLM（Product Lifecycle Management）

## 一、定义

PLM（Product Lifecycle Management，产品生命周期管理）是管理产品从概念、设计、制造、服务到退市全生命周期数据与过程的系统。

- 是研发数据的"单一数据源"（Single Source of Truth）。
- 管理物料、BOM、文档、变更、项目等核心主数据。
- 上承 ERP（生产），下接 MES（执行），横向连接 CAD/EDA。

## 二、产品生命周期阶段

```
概念 → 设计 → 验证 → 试制 → 量产 → 服务 → 退市
 │     │     │     │     │     │     │
 └─PLM 主导────────────────────┘     └─售后SBOM
                                       │
                                    退市归档
```

| 阶段 | PLM 关注点 |
|------|-----------|
| 概念 | 需求、可行性、立项 |
| 设计 | CAD 模型、EBOM、文档 |
| 验证 | 仿真、测试、评审 |
| 试制 | 原型、工艺转化、MBOM |
| 量产 | 变更管理、版本控制 |
| 服务 | SBOM、备件、维修手册 |
| 退市 | 归档、合规留存 |

## 三、核心价值

1. **数据统一**：研发数据集中管理，避免多源不一致。
2. **协同**：跨部门、跨地域协同设计。
3. **过程可控**：评审、变更、发布流程标准化。
4. **知识沉淀**：产品族、技术资料、历史版本可追溯。
5. **降本**：减少重复设计、提升物料重用率。
6. **合规**：满足行业法规（如汽车 IATF16949、医疗 ISO13485）。

## 四、PLM 与周边系统

```
        ┌──── CAD / EDA / CAE ────┐
        │                          │
        ▼                          │
┌───────────────┐                ┌─┴──────────┐
│     PLM       │ ◄── 数据源头 ──►│   ERP      │
│ (物料/BOM/    │                │ (MBOM/采购/ │
│  文档/变更)   │                │  库存/成本) │
└───────┬───────┘                └────────────┘
        │
        ▼
┌───────────────┐
│     MES       │
│ (工艺/工单/   │
│  执行/追溯)   │
└───────────────┘
```

## 五、关键术语

| 术语 | 说明 |
|------|------|
| Item | 物料/对象，PLM 的基本单元 |
| BOM | 物料清单 |
| Document | 技术文档（图纸、规格、测试报告） |
| ECN/ECO | 工程变更通知/工程变更单 |
| Effectivity | 有效性（日期/序列/工单） |
| Revision | 版本（A、B、C 或 1.0、1.1） |
| Lifecycle | 生命周期状态（研发中/试制/量产/失效） |
| Part Family | 零件族（通用化） |
| Variant | 变型（同族不同规格） |

## 六、典型适用行业

- 离散制造：汽车、电子、机械、航空。
- 流程制造：食品配方、化工配方（CBOM）。
- 半导体、医疗器械、装备制造。
