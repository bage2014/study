# PLM 核心模块

> 创建时间：2026-08-16
> 模块：PLM

PLM 系统核心功能模块梳理。

## 一、模块全景

```
┌────────────────────────────────────────────────────────────┐
│                           PLM                              │
├──────────┬──────────┬──────────┬──────────┬────────────────┤
│ 物料管理  │ BOM 管理  │ 文档管理  │ 变更管理  │ 项目管理       │
├──────────┼──────────┼──────────┼──────────┼────────────────┤
│ CAD集成   │ 配置管理  │ 分类与检索 │ 供应商协同 │ 合规/生命周期  │
└──────────┴──────────┴──────────┴──────────┴────────────────┘
```

## 二、各模块说明

### 1. 物料管理（Item Management）

| 能力 | 说明 |
|------|------|
| 物料创建 | 编码生成、属性维护 |
| 物料分类 | 按族、按属性分类 |
| 物料版本 | Revision 版本控制 |
| 生命周期状态 | 研发中/试制/量产/失效 |
| 替代关系 | 主物料与替代料关系 |
| 物料重用 | 查重、推荐重用 |

### 2. BOM 管理

| 能力 | 说明 |
|------|------|
| EBOM 管理 | 设计 BOM 维护 |
| MBOM 转化 | EBOM → MBOM |
| BOM 版本 | 版本与有效性 |
| 多视图 | 设计/制造/服务多视图 |
| BOM 比较 | 版本差异对比 |
| BOM 展开/反查 | 多层展开、where-used |

### 3. 文档管理（Document Management）

| 能力 | 说明 |
|------|------|
| 文档类型 | 图纸、规格、测试报告、工艺文件 |
| 版本控制 | Check-in/Check-out、Revision |
| 文档关联 | 关联物料、BOM、变更 |
| 权限 | 读/写/下载/打印 |
| 格式 | 原生格式（CAD）+ 中性格式（PDF、STEP） |
| 签审 | 在线评审、电子签名 |

### 4. 变更管理（Change Management）

| 能力 | 说明 |
|------|------|
| 变更申请 | ECR（变更请求） |
| 变更评估 | 影响范围、成本、库存 |
| 变更单 | ECN/ECO（变更通知/订单） |
| 变更执行 | 修订物料/BOM/文档 |
| 变更生效 | 有效性切换 |
| 变更追溯 | 变更历史完整记录 |

### 5. 项目管理（Project Management）

研发项目管理。

| 能力 | 说明 |
|------|------|
| 项目立项 | 项目结构、里程碑 |
| 任务分解 | WBS 工作分解 |
| 任务派工 | 责任人、时间 |
| 进度跟踪 | 状态、延期预警 |
| 交付物 | 关联物料、文档 |

### 6. CAD 集成

| 能力 | 说明 |
|------|------|
| 嵌入式 CAD | 在 CAD 中操作 PLM |
| 自动 BOM | 从装配图生成 EBOM |
| 模型管理 | CAD 文件版本 |
| 元数据同步 | 属性双向同步 |
| 可视化 | 轻量化浏览（JT、3D PDF） |

### 7. 配置管理（Configuration Management）

| 能力 | 说明 |
|------|------|
| 模块化 BOM | 配置项定义 |
| 选项/特征 | 选配项与约束 |
| 配置规则 | 互斥、依赖 |
| 实例化 | 配置生成具体 BOM |

### 8. 分类与检索

| 能力 | 说明 |
|------|------|
| 分类树 | 按功能/结构分类 |
| 属性集 | 每类物料属性 |
| 高级检索 | 按属性组合检索 |
| 相似件推荐 | 基于属性相似度 |

### 9. 供应商协同

| 能力 | 说明 |
|------|------|
| 供应商物料 | 制造商件（MFR Part） |
| 认证状态 | 供应商物料认证 |
| 文档共享 | 与供应商共享规格 |
| 变更通知 | 变更同步给供应商 |

### 10. 合规与生命周期

| 能力 | 说明 |
|------|------|
| 法规符合 | RoHS、REACH、冲突矿物 |
| 物质追溯 | 材料成分管理 |
| 退市管理 | 产品 EOL 流程 |
| 数据留存 | 合规留存年限 |

## 三、模块间关系

- 物料是核心，BOM 关联物料，文档关联物料/BOM。
- 变更贯穿物料/BOM/文档。
- 项目管理是研发过程载体，输出物料/BOM/文档。
- CAD 集成是物料/BOM/文档的输入源。
