# PLM 业务流程

> 创建时间：2026-08-16
> 模块：PLM

梳理 PLM 核心业务流程：研发流程、变更流程、BOM 转化流程、文档签审流程。

## 一、新产品研发流程（NPD）

### 阶段-门径模型（Stage-Gate）

```
[立项] → [概念] → [设计] → [验证] → [试制] → [量产]
  G1      G2       G3       G4       G5       G6
```

| 阶段 | 主要活动 | PLM 交付物 |
|------|---------|-----------|
| 立项 | 需求分析、可行性 | 项目、需求文档 |
| 概念 | 方案设计、选型 | 概念 BOM、方案文档 |
| 设计 | 详细设计、CAD | EBOM、图纸、规格 |
| 验证 | 仿真、测试 | 测试报告、验证文档 |
| 试制 | 原型、工艺转化 | MBOM、工艺文件 |
| 量产 | 量产发布 | 发布版本、SOP |

每个 Gate 评审通过方可进入下一阶段。

## 二、物料创建流程

```
1. 申请物料编码
2. 校验：是否已有相似件（推荐重用）
3. 填写属性：分类、单位、规格、供应商
4. 关联文档：图纸、规格书
5. 生命周期：研发中
6. 审核发布
```

### 物料生命周期状态机
```
[研发中] → [试制中] → [已量产] → [受限] → [失效]
              ↓           ↓
          [驳回]      [暂停]
```

## 三、EBOM 创建流程

```
1. 工程师在 CAD 中完成装配设计
2. CAD-PLM 集成：自动生成 EBOM 草稿
3. 工程师校对：补属性、修正层级
4. 关联文档：图纸、规格
5. 提交审核
6. 审核通过：发布为 EBOM 版本 A
```

## 四、EBOM → MBOM 转化流程

### 关键转化动作
| 动作 | 说明 |
|------|------|
| 结构调整 | 按工艺拆分/合并层级 |
| 增加工序 | 每行 BOM 关联工序 |
| 增加用量 | 净用量 + 损耗 |
| 增加虚拟件 | 用于分组、简化 |
| 增加替代料 | 主料/替代料关系 |
| 增加包装件 | 包装材料、标签 |
| 增加辅料 | 油漆、胶水等 |

### 流程
```
1. 复制 EBOM 为 MBOM 草稿
2. 工艺工程师调整结构、补工艺信息
3. 校验：工序匹配、用量合法
4. 提交审核
5. 审核通过：发布 MBOM
6. 同步至 ERP/MES
```

## 五、工程变更流程（ECR → ECN）

### 完整流程
```
1. 提出变更请求 ECR
   ├─ 变更原因
   ├─ 变更内容（物料/BOM/文档）
   └─ 期望生效时间
2. 变更评估
   ├─ 影响范围（反查 BOM）
   ├─ 在制品影响
   ├─ 库存影响（旧料消耗）
   ├─ 客户订单影响
   ├─ 成本影响
   └─ 合规影响
3. 审批 ECR → 升级为 ECN
4. 执行变更
   ├─ 修订物料（新版本）
   ├─ 修订 BOM（新版本）
   ├─ 修订文档（新版本）
   └─ 设定有效性
5. 切换生效
   ├─ 即时 / 日期 / 序列号 / 旧料耗尽
6. 通知下游
   ├─ 同步 ERP
   ├─ 同步 MES
   ├─ 通知采购
   └─ 通知车间
7. 关闭 ECN，归档
```

### 变更评估要点

| 评估项 | 关注 |
|--------|------|
| 反查使用 | 物料/BOM 用在哪些产品 |
| 库存 | 旧料库存如何消耗 |
| 在制品 | 现行工单是否受影响 |
| 采购订单 | 在途订单是否调整 |
| 客户订单 | 已接订单是否允许变更 |
| 成本 | 变更后成本变化 |
| 合规 | 是否触发法规重新认证 |

## 六、文档签审流程

```
1. 工程师 Check-out 文档
2. 修改并 Check-in（生成新版本）
3. 提交评审
4. 评审流：设计 → 校对 → 审核 → 会签 → 批准
5. 通过：发布版本
6. 驳回：返回修改
```

### 评审角色
| 角色 | 职责 |
|------|------|
| 设计 | 编制 |
| 校对 | 同专业校对 |
| 审核 | 专业技术审核 |
| 会签 | 跨专业会签（工艺、质量） |
| 批准 | 授权人批准 |

## 七、产品发布流程

```
1. 物料发布（量产状态）
2. BOM 发布（MBOM 版本生效）
3. 文档发布（SOP、规格书发布版）
4. 工艺路线发布
5. 同步下游：ERP/MES
6. 通知相关部门
```

## 八、退市流程（EOL）

```
1. 提出退市申请
2. 评估：
   ├─ 在制订单
   ├─ 备件需求（售后承诺期）
   └─ 合规留存
3. 退市计划
4. 物料状态：受限 → 失效
5. BOM/文档归档
6. 数据留存（合规年限）
```

## 九、常用规则

| 规则 | 说明 |
|------|------|
| 已发布不可改 | 修订需走变更流程 |
| 版本不可删 | 仅可失效归档 |
| 强制签审 | 关键文档全流程签审 |
| 有效性唯一 | 同一对象同一时刻仅一个有效版本 |
| 源头优先 | 跨系统冲突以源头系统为准 |
