# QMS 质量管理体系 - 概述

> 创建时间：2026-09-06
> 模块：systems

QMS（Quality Management System）质量管理体系系统，覆盖质量策划、控制、保证、改进全流程，区别于 MES 中的质量模块（侧重过程检验），QMS 侧重体系级管理。

## 一、定位

| 范围 | 系统 |
|------|------|
| 过程检验（IQC/IPQC/OQC） | MES 质量模块 |
| 体系级质量（策划、改进、法规） | QMS |

两者集成，MES 提供检验数据，QMS 提供体系管理。

## 二、核心模块

| 模块 | 说明 |
|------|------|
| 质量策划 | 检验计划、控制计划、质量目标 |
| 文档管理 | 质量手册、程序文件、SOP |
| 不合格管理 | NC、隔离、评审、处理 |
| 纠正预防 | CAPA、8D |
| 审核管理 | 内审、外审、管理评审 |
| 质量成本 | 预防成本、鉴定成本、失败成本 |
| 供应商质量 | 供应商质量协议、PPAP |
| 客户投诉 | 投诉处理、8D |
| 质量追溯 | 召回、批次追溯 |
| 质量报表 | 质量看板、趋势分析 |

## 三、质量策划

### 控制计划（Control Plan）
针对产品/过程定义：
- 控制特性（尺寸、性能）
- 控制方法（检验频次、样本量）
- 反应计划（异常处理）

### 检验计划
按物料/工序定义检验项、标准、频次。

## 四、不合格品管理（NC）

```
发现不合格 → 标识/隔离 → 评审 → 处理 → 验证 → 关闭
```

| 处理方式 | 说明 |
|---------|------|
| 返工 | 重新加工达到要求 |
| 返修 | 降级使用 |
| 让步接收 | 有条件放行 |
| 报废 | 直接报废 |
| 退货 | 退供应商 |

## 五、CAPA / 8D

### 8D 方法
| 步骤 | 内容 |
|------|------|
| D0 | 准备 |
| D1 | 成立团队 |
| D2 | 描述问题 |
| D3 | 临时遏制措施 |
| D4 | 根本原因分析（5Why/鱼骨图） |
| D5 | 永久纠正措施 |
| D6 | 实施并验证 |
| D7 | 预防再发生 |
| D8 | 团队表彰/关闭 |

## 六、审核管理

| 审核类型 | 说明 |
|---------|------|
| 内审 | 内部审核，检查体系符合性 |
| 外审 | 第三方认证审核（ISO9001/IATF16949） |
| 管理评审 | 高层评审体系有效性 |
| 过程审核 | 审核特定过程 |
| 产品审核 | 审核产品实物质量 |

## 七、质量成本（COQ）

| 类别 | 项目 |
|------|------|
| 预防成本 | 培训、质量策划、流程改进 |
| 鉴定成本 | 检验、测试、审核 |
| 内部失败成本 | 报废、返工、停机 |
| 外部失败成本 | 客诉、退货、召回、索赔 |

目标：降低失败成本，合理投入预防。

## 八、与 MES 集成

| 接口 | 方向 | 数据 |
|------|------|------|
| 检验数据 | MES → QMS | 检验结果、不良 |
| 控制计划 | QMS → MES | 检验计划下发 |
| 不合格 | MES → QMS | 不合格品信息 |
| CAPA | QMS → MES | 纠正措施执行 |

## 九、行业法规

| 行业 | 标准 |
|------|------|
| 通用 | ISO 9001 |
| 汽车 | IATF 16949 |
| 医疗 | ISO 13485 |
| 航空 | AS 9100 |
| 食品 | ISO 22000 / HACCP |
| 电子 | IPC 标准 |

## 十、设计要点

| 要点 | 说明 |
|------|------|
| 闭环管理 | 问题 → 分析 → 措施 → 验证 → 关闭 |
| 数据驱动 | 质量数据自动采集 |
| 体系合规 | 满足行业标准要求 |
| 持续改进 | PDCA 循环 |
| 跨系统协同 | 与 MES/ERP/SRM 集成 |
