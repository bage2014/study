# WMS 仓储管理系统 - 概述

> 创建时间：2026-09-06
> 模块：systems

WMS（Warehouse Management System）管理仓库出入库、库位、批次、盘点等，与 MES 线边仓、ERP 库存、SRM 送货协同。

## 一、定位

```
ERP（库存账面） ──► WMS（实物管理） ──► MES（线边耗用）
                    │
                    └─ 设备：PDA / AGV / 货架 / 扫码枪
```

- ERP 管"账"（库存数量）。
- WMS 管"实物"（库位、批次、作业）。
- MES 管"车间"（线边库存、耗用）。

## 二、核心模块

| 模块 | 说明 |
|------|------|
| 入库管理 | 收货、质检、上架 |
| 出库管理 | 拣货、复核、打包、发运 |
| 库内管理 | 移库、补货、盘点、冻结 |
| 库存管理 | 批次/序列号、效期、状态 |
| 库位管理 | 库区/库位/容量 |
| 作业管理 | 任务分配、PDA 操作 |
| 条码管理 | 物料/批次/库位条码 |
| 报表 | 库存周转率、库龄、作业效率 |

## 三、入库流程

```
ASN(送货通知) → 收货 → 数量核对 → IQC → 入库上架
```

| 步骤 | 说明 |
|------|------|
| ASN 接收 | 供应商提前通知，生成入库任务 |
| 收货 | 扫送货单条码，实物点数 |
| 收货差异 | 数量不符 → 记录差异 |
| 质检 | IQC 合格 → 状态可用；不合格 → 冻结/退货 |
| 上架 | 系统推荐库位（按物料类别、周转率），PDA 扫码确认 |

## 四、出库流程

```
出库单 → 波次 → 拣货 → 复核 → 打包 → 发运
```

| 步骤 | 说明 |
|------|------|
| 出库单 | 销售/生产/调拨出库单 |
| 波次 | 合并多单，优化拣货路径 |
| 拣货 | PDA 引导拣货，扫条码校验 |
| 复核 | 复核数量/物料正确 |
| 打包 | 包装、贴物流标签 |
| 发运 | 出库，更新库存 |

## 五、库内作业

| 作业 | 说明 |
|------|------|
| 移库 | 库位调整 |
| 补货 | 高位库 → 拣货位补货 |
| 盘点 | 周期盘点/全盘/抽盘 |
| 冻结 | 质量冻结、暂停出入库 |
| 批次合并/拆分 | 批次管理 |

## 六、库存管理

### 库存维度
```
物料 + 批次 + 序列号 + 库位 + 状态 + 效期
```

### 状态
| 状态 | 说明 |
|------|------|
| 可用 | 可出入库 |
| 冻结 | 暂停作业 |
| 在检 | 待质检 |
| 预留 | 已分配给订单 |
| 报废 | 待报废处理 |

### 效期管理
- 保质期物料管理效期。
- FEFO（先到期先出）。
- 临期预警。

## 七、库位管理

### 库位编码
```
库区-巷道-货架-层-位（如 A-01-02-03-04）
```

### 库位属性
| 属性 | 说明 |
|------|------|
| 库位类型 | 存储/拣货/暂存/退货 |
| 容量 | 体积/重量/数量上限 |
| 物料类别 | 允许存放的物料类别 |
| 温区 | 常温/冷藏/冷冻 |

### 上架策略
| 策略 | 说明 |
|------|------|
| 固定库位 | 指定物料固定库位 |
| 随机库位 | 系统推荐空闲库位 |
| 分类存储 | 同类物料同区域 |
| ABC 分类 | A 类近拣货位，C 类远 |

## 八、拣货策略

| 策略 | 说明 | 适用 |
|------|------|------|
| 订单拣货 | 一单到底 | 订单少、品项多 |
| 批量拣货 | 多单合并拣，再分单 | 订单多、品项少 |
| 分区拣货 | 按库区拆分任务 | 大仓库 |
| 波次拣货 | 按时间/区域合并 | 高频出库 |

## 九、与 MES 的协同

### 线边仓协同
- MES 工单配料 → WMS 发料任务 → 配送线边 → MES 确认接收。
- MES 退料 → WMS 退料入库。
- MES 完工 → WMS 成品入库。

### 接口
| 接口 | 方向 | 数据 |
|------|------|------|
| 配料单 | MES → WMS | 工单用料 |
| 发料完成 | WMS → MES | 实际发料批次 |
| 完工入库 | MES → WMS | 成品入库单 |
| 库存查询 | MES → WMS | 可用库存 |

## 十、与 ERP 的协同

| 接口 | 方向 | 数据 |
|------|------|------|
| 入库单 | ERP → WMS | 采购/生产入库 |
| 出库单 | ERP → WMS | 销售/生产出库 |
| 库存同步 | WMS → ERP | 实盘库存 |
| 库存调整 | WMS → ERP | 盘点差异 |

## 十一、设计要点

| 要点 | 说明 |
|------|------|
| 账实一致 | WMS 实物为准，定期同步 ERP |
| 条码驱动 | 全流程扫码，减少差错 |
| 库位精细化 | 到库位级，支撑精准作业 |
| 任务驱动 | PDA 任务推送，无纸化 |
| 批次/序列号 | 贯穿全流程，支撑追溯 |
| 波次优化 | 提升拣货效率 |
