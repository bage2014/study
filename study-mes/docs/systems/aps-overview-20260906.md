# APS 高级计划与排程 - 概述

> 创建时间：2026-09-06
> 模块：systems

APS（Advanced Planning and Scheduling）基于约束的高级计划排程系统，连接 ERP 计划与 MES 执行。

## 一、定位

```
ERP(MPS/MRP) ──► APS(排产) ──► MES(执行)
                  │
                  └─ 约束：物料、产能、工装、人员、交期
```

- ERP 做"做什么、做多少"（无限产能）。
- APS 做"什么时候做、在哪做"（有限产能）。
- MES 做"实际怎么做"。

## 二、核心模块

| 模块 | 说明 |
|------|------|
| 需求计划 | 销售预测、订单需求 |
| 主生产计划 | MPS，产品级周计划 |
| 物料计划 | MRP，物料需求 |
| 产能计划 | CRP，工时需求 |
| 详细排程 | 工序级排产，分配资源 |
| 排程优化 | 多目标优化 |
| 可视化 | 甘特图、资源负载 |

## 三、排程约束

| 约束类型 | 说明 |
|---------|------|
| 物料约束 | BOM 用料齐套 |
| 产能约束 | 设备/产线产能 |
| 工装约束 | 模具/夹具可用性 |
| 人员约束 | 操作工资质、人数 |
| 工艺约束 | 工序顺序、前置关系 |
| 换型约束 | 换型时间、同类合并 |
| 交期约束 | 订单交期 |
| 库存约束 | 半成品/在制品 |

## 四、排程算法

### 常见算法

| 算法 | 说明 | 适用 |
|------|------|------|
| 启发式规则 | 先到先服务、最短加工时间等 | 简单场景 |
| 遗传算法 | 多目标优化 | 复杂约束 |
| 模拟退火 | 局部最优逃离 | 中等 |
| 约束规划(CP) | 约束传播求解 | 强约束 |
| 混合整数规划(MIP) | 数学最优解 | 小规模精确解 |

### 多目标优化

排程通常多目标冲突：
- 最小化延期
- 最大化产能利用率
- 最小化换型时间
- 最小化在制品

用加权或 Pareto 最优处理。

## 五、排程策略

| 策略 | 说明 |
|------|------|
| 前向排产 | 从开始时间往后推 | 最早开工 |
| 后向排产 | 从交期往前推 | 准时交付 |
| 瓶颈优先 | 先排瓶颈资源 | 产能约束强 |
| 订单优先 | 按订单优先级 | 急单优先 |
| 换型最小 | 同类产品合并 | 换型成本高 |

## 六、滚动排产

```
1. 接收 ERP 生产订单
2. 加载当前执行状态（MES 回传）
3. 排产运算
4. 输出工单排程（开始/结束/设备/人员）
5. 下发 MES
6. 事件触发重排：
   ├─ 设备故障
   ├─ 物料缺料
   ├─ 订单变更
   └─ 报工延迟
7. 重新排产未开工部分
```

## 七、与 MES 协同

| 数据 | 方向 | 说明 |
|------|------|------|
| 排产结果 | APS → MES | 工单、工序排程 |
| 实际进度 | MES → APS | 报工、完工 |
| 资源状态 | MES → APS | 设备状态、故障 |
| 物料状态 | MES/WMS → APS | 齐套情况 |

## 八、排程结果可视化

### 甘特图
- 横轴：时间
- 纵轴：设备/产线
- 块：工单工序

### 资源负载图
- 各设备/产线的产能负载率
- 识别瓶颈

### 订单视图
- 订单进度、预计完工、延期风险

## 九、设计要点

| 要点 | 说明 |
|------|------|
| 有限产能 | 区别于 ERP 无限产能 MRP |
| 约束建模 | 完整建模所有约束 |
| 滚动重排 | 事件驱动，非一次性 |
| 与 MES 闭环 | 实际数据回传校正 |
| 可视化 | 甘特图辅助决策 |
| 多目标平衡 | 不追求单一最优 |
