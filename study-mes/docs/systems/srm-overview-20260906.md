# SRM 供应商关系管理 - 概述

> 创建时间：2026-09-06
> 模块：systems

SRM（Supplier Relationship Management）管理供应商全生命周期、采购协同、绩效评估。

## 一、定位

```
ERP(采购订单) ──► SRM(协同门户) ──► 供应商
                  │
                  └─ 寻源、合同、绩效、对账
```

## 二、核心模块

| 模块 | 说明 |
|------|------|
| 供应商管理 | 准入、档案、分类、生命周期 |
| 寻源管理 | RFQ、比价、定标 |
| 采购协同 | 订单确认、ASN、对账 |
| 合同管理 | 合同签订、条款、到期 |
| 绩效评估 | 质量、交期、价格、服务 |
| 质量协同 | IQC 反馈、8D 报告 |
| 财务协同 | 对账单、发票 |

## 三、供应商全生命周期

```
潜在供应商 → 准入评审 → 认证 → 合格供应商 → 绩效评估 → 分级 → 退出
```

| 阶段 | 说明 |
|------|------|
| 潜在 | 初步接触，收集信息 |
| 准入 | 资质审核（营业执照、认证） |
| 认证 | 样品测试、现场审核 |
| 合格 | 纳入合格名录，可下单 |
| 绩效 | 定期评估，动态分级 |
| 分级 | A/B/C/D 级，分配订单比例 |
| 退出 | 绩效不合格或主动退出 |

## 四、寻源流程

```
采购需求 → 供应商筛选 → RFQ(询价) → 报价 → 比价 → 定标 → 合同
```

### 比价维度
| 维度 | 权重 |
|------|------|
| 价格 | 50% |
| 交期 | 20% |
| 质量历史 | 20% |
| 服务/响应 | 10% |

## 五、采购协同

| 协同点 | 说明 |
|--------|------|
| 订单确认 | 供应商在线确认 PO，确认交期 |
| ASN | 供应商提前通知送货 |
| 收货确认 | WMS 收货后同步供应商 |
| 对账 | 在线对账，生成对账单 |
| 发票 | 供应商在线开票 |
| 质量反馈 | IQC 不合格通知供应商 |
| 8D 报告 | 供应商提交纠正预防措施 |

## 六、供应商绩效

### 评估维度

| 维度 | 指标 | 数据来源 |
|------|------|---------|
| 质量 | 来料合格率、PPM | MES/ERP |
| 交期 | 准时交付率 | ERP/WMS |
| 价格 | 价格竞争力 | 采购数据 |
| 服务 | 响应速度、问题处理 | 人工评分 |

### 分级与奖惩
| 等级 | 订单比例 | 措施 |
|------|---------|------|
| A 级（战略） | 优先 | 长期合同、联合开发 |
| B 级（优秀） | 正常 | 正常合作 |
| C 级（合格） | 减少 | 限期改进 |
| D 级（不合格） | 淘汰 | 退出名录 |

## 七、与 ERP 集成

| 接口 | 方向 | 数据 |
|------|------|------|
| 供应商主数据 | ERP → SRM | 供应商档案 |
| 采购订单 | ERP → SRM | PO |
| ASN | SRM → ERP/WMS | 送货通知 |
| 收货 | WMS → SRM | 收货确认 |
| 发票 | SRM → ERP | 发票信息 |

## 八、设计要点

| 要点 | 说明 |
|------|------|
| 门户化 | 供应商自助，减少人工 |
| 数据自动采集 | 绩效数据来自业务系统，非手工 |
| 动态分级 | 绩效驱动订单分配 |
| 闭环改进 | 质量问题 → 8D → 验证 |
| 合同管控 | 价格、交期条款电子化 |
