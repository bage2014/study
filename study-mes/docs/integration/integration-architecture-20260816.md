# 系统集成架构（MES / BOM / PLM / ERP）

> 创建时间：2026-08-16
> 模块：integration

梳理制造企业核心业务系统的集成关系、数据流向、接口设计要点。

## 二、各系统职责边界

| 系统 | 核心职责 | 关键数据 |
|------|---------|---------|
| PLM | 研发数据源 | 物料、EBOM、MBOM、文档、变更 |
| ERP | 计划与资源 | 销售订单、生产订单、采购、库存、成本 |
| MES | 车间执行 | 工单、报工、质量、设备、追溯 |
| WMS | 仓储管理 | 出入库、批次、库位 |
| SRM | 供应商协同 | 采购订单、送货、对账 |
| CRM | 客户管理 | 客户、商机、订单 |

## 三、数据流向（端到端）

### 1. 研发 → 量产 主数据流

```
PLM
 ├─ 物料主数据      ──► ERP（物料档案）
 ├─ EBOM           ──► ERP（设计 BOM 参考）
 ├─ MBOM           ──► ERP（生产 BOM）
 │                  └─► MES（工艺 BOM、用料）
 ├─ 工艺路线        ──► ERP（工作中心、路线）
 │                  └─► MES（工序定义）
 ├─ 文档（SOP/图纸）──► MES（工艺文档下发）
 └─ 变更（ECN）     ──► ERP / MES（同步变更）
```

### 2. 销售订单 → 生产 → 发货 业务流

```
1. CRM/ERP 录入销售订单
2. ERP MRP 运算（基于 MBOM + 库存）
3. 生成生产订单 + 采购申请
4. 采购订单 → SRM → 供应商送货 → WMS 入库
5. 生产订单 → MES 工单
6. MES 执行：配料（WMS 出库）→ 报工 → 质检
7. 完工入库 → WMS
8. 发货 → WMS 出库 → 客户
9. 成本核算 → ERP
```

## 四、核心接口清单

### PLM → ERP
| 接口 | 触发 | 数据 |
|------|------|------|
| 物料发布 | 物料审核通过 | 物料编码、属性 |
| MBOM 发布 | MBOM 审核通过 | MBOM 版本 |
| 工艺路线发布 | 路线审核通过 | 工序、工作中心 |
| 变更通知 | ECN 生效 | 变更内容、有效性 |

### ERP → MES
| 接口 | 触发 | 数据 |
|------|------|------|
| 工单下达 | 工单创建 | 工单号、产品、数量、工艺版本 |
| 工单变更 | 工单修改 | 修改字段 |
| 工单关闭 | 工单关闭 | 关闭状态 |
| 物料主数据 | 物料变更 | 物料档案 |

### PLM → MES
| 接口 | 触发 | 数据 |
|------|------|------|
| MBOM 同步 | MBOM 发布 | MBOM、工序 BOM |
| 工艺文档 | 文档发布 | SOP、图纸 PDF |
| 工艺参数 | 参数发布 | 工序参数标准 |

### MES → ERP
| 接口 | 触发 | 数据 |
|------|------|------|
| 报工回传 | 工序报工 | 工单、数量、工时 |
| 完工入库 | 工单完工 | 入库单 |
| 质量数据 | 检验完成 | 检验结果 |
| 物料消耗 | 报工扣料 | 物料批次、用量 |

### MES ↔ WMS
| 接口 | 触发 | 数据 |
|------|------|------|
| 配料请求 | 工单齐套 | 配料单 |
| 配料完成 | WMS 配料 | 配料结果 |
| 入库 | 完工 | 入库单 |
| 领料 | 车间领用 | 领料单 |

## 五、集成模式选择

| 场景 | 推荐模式 | 理由 |
|------|---------|------|
| 主数据同步 | 消息（异步） | 解耦、可靠 |
| 工单下达 | 消息（异步） | 解耦 |
| 报工回传 | 消息（异步） | 批量、解耦 |
| 即时查询 | REST（同步） | 实时性 |
| 大批量同步 | ETL（定时） | 性能 |
| 跨企业 | API 网关 | 安全、可控 |

## 六、数据一致性策略

### 主数据治理
- **源头唯一**：物料主数据源 PLM，BOM 源 PLM。
- **分发机制**：通过消息广播变更事件。
- **最终一致**：允许短时延迟，确保最终一致。
- **对账机制**：定期比对跨系统数据。

### 工单数据一致性
- ERP 工单为权威，MES 镜像。
- 状态变更通过事件同步。
- 关键操作（关闭）走 ERP 主导。

### 版本与有效性
- 工单下达时锁定 BOM/工艺版本。
- 变更不影响在制工单（除非显式切换）。
- 跨系统版本号同步。

## 七、集成关键技术

| 技术 | 用途 |
|------|------|
| 消息中间件（Kafka/RocketMQ） | 异步解耦、事件驱动 |
| API 网关 | 统一入口、鉴权、限流 |
| 分布式事务 | 跨系统数据一致性（Saga / TCC） |
| 幂等设计 | 重复消息安全处理 |
| 链路追踪（SkyWalking） | 跨系统问题定位 |
| 数据对账平台 | 数据一致性监控 |

## 八、典型集成问题与对策

| 问题 | 对策 |
|------|------|
| 数据不一致 | 源头唯一 + 对账机制 |
| 接口失败重试风暴 | 退避重试 + 死信队列 |
| 跨系统性能瓶颈 | 异步化 + 削峰填谷 |
| 版本不一致 | 严格版本管理 + 锁定机制 |
| 字段映射混乱 | 字典表统一管理 |
| 老旧系统协议不兼容 | 适配层 + 文件交换 |

## 九、参考架构（事件驱动）

```
┌─────┐   ┌─────┐   ┌─────┐
│ PLM │   │ ERP │   │ WMS │
└──┬──┘   └──┬──┘   └──┬──┘
   │         │         │
   ▼         ▼         ▼
┌──────────────────────────────┐
│       消息总线 (Kafka)         │
│  topic: item / bom / order /  │
│         workorder / report    │
└──────────────┬────────────────┘
               │
               ▼
        ┌────────────┐
        │    MES     │
        └────────────┘
```

- 事件驱动：变更即事件，订阅方按需消费。
- 解耦：生产者不感知消费者。
- 可扩展：新增系统订阅即可。
