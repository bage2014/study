# 主流产品方案对比

> 创建时间：2026-09-06
> 模块：products

MES/PLM/ERP 等工业系统主流产品方案对比，含国内外厂商、开源方案、选型建议。

## 一、方案类型

| 类型 | 代表 | 特点 | 适用 |
|------|------|------|------|
| 国际大厂 | SAP、Oracle、西门子 | 功能全、贵、重 | 大型集团 |
| 国内大厂 | 用友、金蝶、鼎捷 | 本地化好、中等 | 中大型 |
| 行业垂直 | 宝信（钢铁）、和利时 | 行业深度 | 特定行业 |
| 开源 | Odoo、OpenMRS | 免费、需自建 | 小团队/定制 |
| SaaS | 黑湖、智造家 | 轻量、订阅 | 中小企业 |
| 自研 | - | 完全可控 | 有 IT 能力 |

## 六、选型建议

### 按企业规模

| 规模 | 推荐 |
|------|------|
| 大型集团（万人以上） | SAP / Oracle，配套西门子 MES / Teamcenter PLM |
| 中大型（千人级） | 用友/金蝶 ERP + 行业 MES + 国内 PLM |
| 中型（百人级） | 金蝶云 + 黑湖 MES / 自研 MES + 轻量 PLM |
| 小型 | SaaS 方案 / Odoo + 自研 MES |

### 按行业

| 行业 | 推荐方案 |
|------|---------|
| 汽车零部件 | SAP + 西门子 MES + Teamcenter（IATF 合规） |
| 电子制造 | 金蝶/用友 + 云科 MES + 思普 PLM |
| 钢铁冶金 | 宝信全套（行业深度） |
| 化工流程 | SAP + 和利时 MES |
| 装备制造 | 鼎捷 ERP + 行业 MES + Teamcenter |
| 半导体 | Oracle Agile + 行业 MES（SECS/GEM） |

### 选型维度

| 维度 | 说明 |
|------|------|
| 功能匹配 | 核心业务覆盖率 |
| 行业深度 | 行业方案成熟度 |
| 集成能力 | 与现有系统集成 |
| 实施成本 | 软件+实施+运维 |
| 本地化 | 中文、法规、服务 |
| 可扩展性 | 二次开发能力 |
| 厂商实力 | 持续服务能力 |
| 用户体验 | 操作便捷性 |

## 七、自研 vs 外购决策

| 自研 | 外购 |
|------|------|
| 完全可控 | 上线快 |
| 完全匹配需求 | 行业最佳实践 |
| 长期成本高 | 长期依赖厂商 |
| 需 IT 团队 | 定制受限 |

**建议**：
- 通用能力（财务、库存）外购。
- 核心差异化能力（行业工艺、追溯）自研或深度定制。
- 混合：外购 ERP/MES 底座，自研行业插件。

## 八、实施风险

| 风险 | 对策 |
|------|------|
| 需求不清 | 蓝图先行、原型验证 |
| 数据质量 | 主数据治理先行 |
| 用户抵触 | 培训、试点、推广 |
| 集成复杂 | 接口规范、试点 |
| 范围蔓延 | 严格变更管理 |
| 厂商能力不足 | 严格选型、驻场 |
