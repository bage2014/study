# BOM 业务流程

> 创建时间：2026-08-16
> 模块：BOM

梳理 BOM 从创建、变更到展开使用的关键流程。

## 一、BOM 全生命周期

```
创建 → 校验 → 审核 → 发布 → 使用
                  ↑        ↓
                  └── 变更 ┘
                          ↓
                       归档/失效
```

## 二、BOM 创建流程

### 流程
```
1. 研发在 PLM 中设计产品结构
2. 由 CAD 装配图自动生成 EBOM 草稿
3. 工艺工程师基于 EBOM 转化为 MBOM
4. 补充：工序、用量、损耗、替代料
5. 提交审核
```

### 校验规则
| 校验项 | 说明 |
|--------|------|
| 物料存在性 | 子/父物料编码必须在物料主数据中 |
| 循环引用 | 禁止 A→B→A 自循环 |
| 用量合法性 | > 0，且非异常大值 |
| 唯一性 | 同一父+子+有效性不重复 |
| 工序匹配 | MBOM 工序必须在工艺路线中 |

## 三、BOM 审核与发布

### 状态机
```
[草稿] → [审核中] → [已发布] → [失效]
              ↓
          [驳回] → [草稿]
```

### 审核要点
- 结构合理性（层级、虚拟件）。
- 用量、损耗合理性。
- 工序对应正确。
- 替代料是否合规。

### 发布动作
- 冻结版本号。
- 设置生效日期。
- 同步至 ERP/MES。

## 四、BOM 变更流程（ECN/ECO）

### 变更类型
| 类型 | 说明 | 触发 |
|------|------|------|
| 增 | 新增子件 | 设计优化、新功能 |
| 删 | 删除子件 | 停用、替代 |
| 改 | 修改用量/工序 | 工艺改进 |
| 换 | 替代料调整 | 供应商切换 |

### 变更流程
```
1. 提出变更申请（ECN/ECO）
2. 影响评估：
   ├─ 在制品影响
   ├─ 库存影响（旧料消耗）
   ├─ 客户订单影响
   └─ 成本影响
3. 审批
4. 切换方案：
   ├─ 即时切换
   ├─ 旧料耗尽切换
   └─ 日期切换
5. 生效：新版本发布，旧版本失效
6. 通知：ERP/MES/采购/车间
```

### 切换策略
| 策略 | 适用场景 |
|------|---------|
| 即时切换 | 紧急质量、安全问题 |
| 旧料耗尽 | 通用物料，库存成本高 |
| 日期切换 | 正常迭代 |
| 序列号切换 | 按产品序列号生效 |

## 五、BOM 展开流程

### 单层展开
查父件的直接子件。

### 多层展开
递归展开全部层级，直到采购件。

### 示例
```
输入：产品 A
输出：
  ├─ B (1)
  │   ├─ X (2)
  │   └─ Y (3)
  ├─ C (1)
  │   └─ Z (5)
  └─ D (4)
```

### 展开算法
```
function expand(parent, qty):
    for line in bom.lines(parent):
        childQty = qty * line.qty * (1 + line.lossRate)
        if isPhantom(line.child):
            expand(line.child, childQty)  # 跳过虚拟件，直接展开下层
        else:
            result.add(line.child, childQty)
            if hasBom(line.child):
                expand(line.child, childQty)
```

## 六、BOM 反查流程

查某物料用于哪些父件，用于影响评估。

```
输入：物料 X
输出：
  ├─ 用于 B（用量 2）
  │   └─ B 用于 A（用量 1）
  └─ 用于 D（用量 5）
```

## 七、MRP 运算（BOM 的核心消费）

### 流程
```
1. 输入：销售订单 + 预测 + 库存 + BOM + 工艺
2. BOM 多层展开，计算净需求
3. 净需求 = 毛需求 - 可用库存
4. 生成：生产建议、采购建议
5. 考虑：提前期、批量、安全库存
```

## 八、BOM 数据治理要点

| 要点 | 说明 |
|------|------|
| 编码规范 | 物料编码统一规则 |
| 唯一数据源 | PLM 为 EBOM 唯一源，ERP 为 MBOM 唯一源 |
| 变更闭环 | 变更必须走 ECN 流程 |
| 版本一致性 | 跨系统版本同步 |
| 周期审计 | 定期检查异常 BOM |

## 九、常见异常与处理

| 异常 | 处理 |
|------|------|
| 循环引用 | 创建时校验拦截 |
| 用量异常 | 审核时人工复核 |
| 物料未发布 | 禁止 BOM 引用未发布物料 |
| 多版本并存 | 按有效性明确生效范围 |
| 跨系统不一致 | 定期对账，以源头为准 |
