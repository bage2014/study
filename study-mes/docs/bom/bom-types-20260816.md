# BOM 类型详解

> 创建时间：2026-08-16
> 模块：BOM

不同部门、不同阶段使用不同类型的 BOM。理解类型差异是 BOM 管理的基础。

## 一、常见 BOM 类型对比

| 类型 | 全称 | 产生阶段 | 主要用户 | 关注点 |
|------|------|---------|---------|--------|
| EBOM | Engineering BOM | 设计 | 研发工程师 | 设计结构、功能 |
| MBOM | Manufacturing BOM | 工艺 | 工艺/生产 | 工序、用量、损耗 |
| SBOM | Service BOM | 售后 | 售后服务 | 备件、维修 |
| DBOM | Design BOM | 概念 | 系统工程师 | 系统级分解 |
| CBOM | Configurable BOM | 配置 | 销售/配置 | 选配、模块化 |
| BBOM | Budget BOM | 报价 | 销售/财务 | 估算成本 |

## 二、EBOM（工程 BOM）

### 特征
- 来自 CAD/PLM，反映设计意图。
- 严格按设计图纸层级。
- 用量为设计理论值，不含损耗。
- 关注功能与结构，不关心采购/工艺。

### 字段示例
```
父件：产品 A
├── 部件 B（1）
│   ├── 零件 B-1（1）
│   └── 标准件 M6 螺栓（4）
└── 部件 C（1）
```

## 三、MBOM（制造 BOM）

### 特征
- 在 EBOM 基础上增加工艺信息。
- 含工序、工位、用量、损耗、虚拟件。
- 是 MES/ERP 生产的核心依据。
- 可能与 EBOM 层级不同（拆分/合并）。

### 与 EBOM 差异
| 维度 | EBOM | MBOM |
|------|------|------|
| 来源 | CAD | 工艺设计 |
| 层级 | 设计层级 | 制造层级 |
| 用量 | 净用量 | 含损耗 |
| 工序 | 无 | 有 |
| 虚拟件 | 通常无 | 常用 |
| 替代料 | 通常无 | 有 |
| 包装件 | 无 | 有 |

### MBOM 字段示例
```
父件：产品 A  工序：装配10
├── 部件 B（1）  工序：装配10
│   ├── 零件 B-1（1）  工序：加工05
│   └── M6 螺栓（4+5%损耗）  工序：装配10
├── 包装箱（1）  工序：包装30
└── 标签（1）  工序：包装30
```

## 四、SBOM（服务 BOM）

### 特征
- 服务/维修视角的 BOM。
- 含备件清单、维修层级、易损件标识。
- 可能比 EBOM/MBOM 更粗（只列可换件）。

## 五、CBOM（可配置 BOM）

### 特征
- 模块化产品配置。
- 含选配项、特征、约束规则。
- 选配后生成具体实例 BOM。

### 示例
```
产品 = 基础模块 + [发动机选型] + [颜色选型] + [轮毂选型]
发动机：A型 / B型（互斥）
颜色：红 / 蓝 / 黑（互斥）
轮毂：17寸 / 18寸（互斥）
```

## 六、BOM 类型转换链路

```
DBOM → EBOM → MBOM → SBOM
              ↓
            CBOM（可配置衍生）
```

- DBOM/EBOM 来自 PLM。
- MBOM 由工艺部门在 PLM 或 ERP 中转化生成。
- SBOM 由售后部门基于 MBOM 简化。
- CBOM 由产品配置器从 EBOM/MBOM 衍生。

## 七、版本与有效性

### 版本管理
- 每次变更生成新版本。
- 旧版本归档，不可删除。
- 工单下达时锁定 BOM 版本。

### 有效性
- **日期有效**：按生效/失效日期。
- **序列号有效**：按产品序列号区间。
- **工单有效**：按工单锁定。

## 八、虚拟件详解

### 用途
1. 简化 BOM 结构，便于管理通用组件。
2. 不实际入库，需求直接传递到下层。
3. MRP 展开时跳过虚拟件层级。

### 示例
```
产品 A
└── [虚拟件] 通用紧固件包
    ├── M6 螺栓（4）
    ├── M6 垫片（4）
    └── M6 螺母（4）
```
配料时直接领 4 个螺栓/垫片/螺母，无"通用紧固件包"库存。
