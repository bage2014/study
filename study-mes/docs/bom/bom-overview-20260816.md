# BOM 物料清单 - 概述

> 创建时间：2026-08-16
> 模块：BOM（Bill of Materials）

## 一、定义

BOM（Bill of Materials，物料清单）是描述产品由哪些物料构成、构成关系与数量的结构化清单。

- 是产品的"配方"或"配方表"。
- 贯穿研发、工艺、生产、采购、成本全链路。
- 是 ERP/MES/PLM 的核心主数据。

## 二、核心作用

| 场景 | BOM 的作用 |
|------|-----------|
| 研发 | 表达设计意图，定义产品结构 |
| 工艺 | 关联工序、形成 BOP |
| 生产 | 指导配料、领料、装配 |
| 采购 | 推算采购需求（MRP） |
| 成本 | 核算材料成本 |
| 质量 | 物料批次追溯依据 |
| 售后 | 维修备件清单 |

## 三、BOM 的关键属性

### 单行字段（BOM Line）

| 字段 | 说明 |
|------|------|
| 父物料 | 上级物料编码 |
| 子物料 | 下级物料编码 |
| 用量 | 子物料数量（相对父物料单位） |
| 用量类型 | 固定量 / 比例 / 公式 |
| 损耗率 | 加工损耗百分比 |
| 位置号 | 在装配图中的位置（如 R1、C3） |
| 工序 | 子物料在哪道工序投入 |
| 替代料 | 可替代的物料编码 |
| 生效/失效 | 日期有效性 |
| 虚拟件标识 | 是否为虚拟件（Phantom） |

### 头字段（BOM Header）

| 字段 | 说明 |
|------|------|
| BOM 编码 | 唯一标识 |
| 父物料 | BOM 所属产品 |
| BOM 类型 | EBOM/MBOM/SBOM 等 |
| 版本 | 版本号 |
| 状态 | 草稿/审核中/已发布/失效 |
| 工厂 | 适用工厂 |
| 生效日期 | 启用日期 |

## 四、BOM 的层级结构

```
成品 A
├── 半成品 B（1）
│   ├── 原料 X（2）
│   └── 原料 Y（3）
├── 半成品 C（1）
│   └── 原料 Z（5）
└── 标准件 D（4）
```

- 树状结构，可多层嵌套。
- 末端节点通常为采购件（原材料、标准件）。
- 中间节点可能为自制件、半成品、虚拟件。

## 五、关键概念

| 概念 | 说明 |
|------|------|
| 虚拟件（Phantom） | 不实际入库的中间件，仅为分组/简化结构 |
| 替代料 | 主料缺货时可用替代 |
| 选用件 | 可选配置（如颜色、容量） |
| 用量公式 | 用量随参数变化（如长度、面积） |
| BOM 展开 | 自顶向下逐层分解 |
| BOM 反查 | 查某物料用于哪些父件 |
| 单层 BOM | 只含直接子件 |
| 多层 BOM | 含全部下层子件 |

## 六、BOM 与其他系统的关系

- **PLM**：BOM 设计源头，EBOM 在此产生。
- **ERP**：BOM 主数据存储，MRP 运算基础。
- **MES**：消费 MBOM，指导现场生产。
- **SRM/WMS**：依据 BOM 采购、配料。
