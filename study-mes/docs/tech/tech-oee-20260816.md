# 设备 OEE 计算

> 创建时间：2026-08-16
> 模块：tech

OEE（设备综合效率）的定义、计算逻辑、数据采集、工程实现。

## 一、OEE 定义

```
OEE = 可用率 × 性能率 × 质量率
        │         │         │
        └─ 时间    └─ 速度    └─ 不良
```

### 公式

| 指标 | 公式 |
|------|------|
| 可用率 A | 计划生产时间 / 可用时间 |
| 性能率 P | 实际产量 × 理论节拍 / 计划生产时间 |
| 质量率 Q | 合格产量 / 实际产量 |
| OEE | A × P × Q |

### 时间分解

```
日历时间
├── 非计划时间（节假日/无订单）
└── 可用时间 = 计划时间
    ├── 计划停机（保养/换型/休息）
    └── 计划生产时间
        ├── 设备停机（故障/待料/待机）
        └── 运行时间
            ├── 净运行时间（满速理论）
            │   ├── 合格品时间
            │   └── 不良品时间
            └── 速度损失时间
```

## 二、损失分类（六大损失）

| 类别 | 损失 | 对应指标 |
|------|------|---------|
| 设备 | 故障停机 | 可用率 |
| 设备 | 换型/调整 | 可用率 |
| 速度 | 空闲/微停 | 性能率 |
| 速度 | 速度降低 | 性能率 |
| 质量 | 工序不良（返工/报废） | 质量率 |
| 质量 | 启动损失（试产不良） | 质量率 |

## 三、数据模型

```sql
oee_record (OEE 记录，按班次/设备)
├── id

├── plant_id

├── id
├── device_id
├── shift_date

├── end_time
```

## 四、计算实现

```java
@Service
public class OeeCalculator {

    public OeeResult calculate(Long deviceId, Shift shift) {
        // 1. 时间维度
        int plannedTime = plannedTime(deviceId, shift);        // 计划生产时间
        int downtime = sumDowntime(deviceId, shift);           // 停机时间
        int runTime = plannedTime - downtime;                   // 运行时间

        double availability = plannedTime == 0 ? 0 : (double) runTime / plannedTime;

        // 2. 速度维度
        double idealCycleTime = device.getIdealCycleTime();     // 理论节拍（秒/件）
        int totalCount = countService.getTotal(deviceId, shift);
        double netRunTime = totalCount * idealCycleTime / 60;   // 净运行时间（分）

        double performance = runTime == 0 ? 0 : netRunTime / runTime;

        // 3. 质量维度
        int goodCount = countService.getGood(deviceId, shift);
        double quality = totalCount == 0 ? 0 : (double) goodCount / totalCount;

        // 4. OEE
        double oee = availability * performance * quality;

        return new OeeResult(availability, performance, quality, oee,
            plannedTime, downtime, runTime, totalCount, goodCount);
    }
}
```

## 五、停机时间采集

### 自动采集
设备状态变更即记录：

```java
@EventListener
public void onStatusChange(DeviceStatusChangedEvent event) {
    DeviceStatus newStatus = event.newStatus();
    DeviceStatus prev = device.getStatus();

    if (prev == RUNNING && newStatus != RUNNING) {
        // 开始停机
        DowntimeRecord rec = DowntimeRecord.start(event.deviceId(), newStatus);
        downtimeRepo.save(rec);
    } else if (prev != RUNNING && newStatus == RUNNING) {
        // 结束停机
        downtimeRepo.findOpen(event.deviceId()).ifPresent(rec -> {
            rec.end(now());
            downtimeRepo.save(rec);
        });
    }
}
```

### 手工录入
故障原因、待料原因等需人工补录：

```java
public void assignReason(Long downtimeId, String reasonCode) {
    DowntimeRecord rec = downtimeRepo.findOrThrow(downtimeId);
    rec.setReasonCode(reasonCode);
    downtimeRepo.save(rec);
}
```

## 八、多设备聚合

```java
public OeeSummary plantOee(Long plantId, LocalDate date) {
    List<OeeRecord> records = oeeRepo.findByPlantAndDate(plantId, date);
    int totalPlanned = records.stream().mapToInt(OeeRecord::getPlannedTime).sum();
    int totalRun = records.stream().mapToInt(OeeRecord::getRunTime).sum();
    int totalCount = records.stream().mapToInt(OeeRecord::getTotalCount).sum();
    int totalGood = records.stream().mapToInt(OeeRecord::getGoodCount).sum();

    // 加权平均（按时间权重），非简单平均
    double a = totalPlanned == 0 ? 0 : (double) totalRun / totalPlanned;
    double p = totalRun == 0 ? 0 : (totalCount * avgCycleTime / 60) / totalRun;
    double q = totalCount == 0 ? 0 : (double) totalGood / totalCount;
    return new OeeSummary(a, p, q, a * p * q);
}
```

**关键**：聚合用加权平均（按时间/产量权重），非简单算术平均，否则失真。

## 九、趋势与对标

### 趋势
按班次/日/周展示 OEE 走势，识别下降趋势。

### 对标
- 班次对标（A 班 vs B 班）
- 设备对标（同类型设备）
- 行业对标（世界级 OEE ≈ 85%，典型 ≈ 60%）

### 损失分析
```java
public LossAnalysis analyze(Long deviceId, LocalDate from, LocalDate to) {
    List<DowntimeRecord> downtimes = downtimeRepo.findByDevice(deviceId, from, to);
    // 按原因分组，识别 Top 损失
    Map<String, Integer> byReason = downtimes.stream()
        .collect(groupingBy(DowntimeRecord::getReasonCode,
            summingInt(DowntimeRecord::getDuration)));
    // 柏拉图：80/20 关键损失
    return Pareto.of(byReason);
}
```

## 十、常见陷阱

| 陷阱 | 对策 |
|------|------|
| 用算术平均聚合 | 改加权平均 |
| 理论节拍不准 | 定期维护、实测校准 |
| 停机原因漏录 | 强制闭环、超时提醒 |
| 微停不计 | 设置最小停机时长（如 < 1 分钟不计） |
| 不良数来源混乱 | 统一来自检验模块 |
| OEE 指标定义不统一 | 明确口径，全厂一致 |

## 十一、设计要点

| 要点 | 说明 |
|------|------|
| 班次维度计算 | 按班次而非按日，粒度合适 |
| 加权聚合 | 避免失真 |
| 停机原因闭环 | 必须录入原因 |
| 节拍维护 | 设备-产品映射 |
| 自动+人工结合 | 状态自动，原因人工 |
| 趋势监控 | 下降及时干预 |
