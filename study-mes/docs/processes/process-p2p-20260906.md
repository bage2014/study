# 采购到付款流程（P2P - Procure to Pay）

> 创建时间：2026-09-06
> 模块：processes

从需求产生到付款的全链路，涉及 MES/ERP/SRM/WMS/财务。

## 一、流程全景

```
需求 → 采购申请 → 询价比价 → 采购订单 → 送货 → 收货(IQC) → 入库 → 发票 → 付款
 ERP        ERP     SRM        ERP/SRM    SRM    WMS/MES    WMS    财务  财务
```

## 二、阶段拆解

### 1. 需求产生

| 来源 | 系统 | 说明 |
|------|------|------|
| MRP 运算 | ERP | 基于 BOM + 库存 + 订单自动算需求 |
| 手工请购 | ERP | 安全库存补货、研发试样 |
| 车间领料 | MES | 工单用料 |
| 间接采购 | ERP | 办公用品、设备 |

### 2. 采购申请（PR）

```
请购单 → 审批（按金额分级） → 转采购订单
```

### 3. 寻源与询价比价（SRM）

| 步骤 | 说明 |
|------|------|
| 供应商选择 | 按品类、认证状态筛选 |
| 询价（RFQ） | 向多家供应商询价 |
| 比价 | 价格、交期、质量评分 |
| 定标 | 确定供应商、价格 |

### 4. 采购订单（PO）

```
采购订单 → 审批 → 发送供应商（SRM 门户）
                → 供应商确认（确认交期/数量）
```

### 5. 供应商送货（SRM）

```
供应商创建送货单（ASN） → 打印条码 → 送货
```

ASN（Advanced Shipping Notice）提前通知，便于仓库收货准备。

### 6. 收货与质检（WMS/MES）

```
1. WMS 收货：扫码核对送货单 vs 采购订单
2. 数量校验
3. 触发 IQC 检验
   ├─ 免检 → 直接入库
   └─ 需检 → 品质检验
4. 检验结果：
   ├─ 合格 → 入库上架
   └─ 不合格 → 退货/让步接收/换货
```

### 7. 入库（WMS）

```
上架 → 库位分配 → 库存更新 → 库存事务记录
```

### 8. 发票校验与付款（财务）

```
1. 供应商开票
2. 三单匹配：采购订单 vs 收货单 vs 发票（数量、金额一致）
3. 应付单生成
4. 付款审批
5. 付款执行 → 核销
```

## 三、关键接口

| 接口 | 源 → 目标 | 数据 |
|------|----------|------|
| 采购需求 | ERP → SRM | 采购申请 |
| PO 下发 | ERP → SRM | 采购订单 |
| ASN | SRM → WMS | 送货通知 |
| 收货 | WMS → ERP | 收货单 |
| 检验结果 | MES → ERP/WMS | IQC 结果 |
| 入库 | WMS → ERP | 入库单 |
| 发票 | SRM → ERP | 发票信息 |

## 四、三单匹配

财务付款前的核心校验：

```
采购订单(PO)  ─┐
收货单(GR)    ─┼─ 匹配 ─► 一致 → 生成应付
发票(IV)      ─┘           不一致 → 冻结，人工处理
```

匹配维度：
- 物料编码一致
- 数量一致（允许容差）
- 单价一致
- 总金额一致

## 五、异常处理

| 异常 | 处理 |
|------|------|
| 送货数量不符 | 实收数量入库，差异索赔/补发 |
| 质检不合格 | 退货单/让步接收单 |
| 价格不符 | 冻结发票，与供应商协商 |
| 交期延误 | 按合同索赔，影响供应商评分 |
| 供应商绩效低 | 减少订单，重新寻源 |

## 六、供应商绩效

SRM 持续评估供应商：

| 维度 | 指标 |
|------|------|
| 质量 | 来料合格率、PPM |
| 交期 | 准时交付率 |
| 价格 | 价格竞争力 |
| 服务 | 响应速度、问题处理 |

定期评审，优胜劣汰。

## 七、KPI

| 指标 | 说明 |
|------|------|
| 采购周期 | PR → PO 平均时长 |
| 来料合格率 | IQC 合格率 |
| 准时交付率 | 供应商按时交货占比 |
| 应付周转天数 | 付款速度 |
| 采购成本节约率 | 同比降本 |
