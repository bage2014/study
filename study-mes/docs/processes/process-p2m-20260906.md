# 计划到生产流程（P2M - Plan to Manufacture）

> 创建时间：2026-09-06
> 模块：processes

从销售/预测到生产完工的计划执行链路，是 MES 核心上游。

## 一、流程全景

```
预测/订单 → S&OP → 主生产计划(MPS) → 物料需求(MRP) → 能力计划(CRP)
                                                        │
                                    排产(APS) ◄─────────┘
                                        │
                                        ▼
                                  工单下达 → 生产执行(MES) → 完工入库
```

## 二、阶段拆解

### 1. 需求管理

| 输入 | 说明 |
|------|------|
| 销售订单 | 已确认订单 |
| 销售预测 | 历史+市场预测 |
| 安全库存 | 缓冲库存 |

### 2. S&OP（销售与运营计划）

```
销售预测 + 产能评估 + 库存策略 → 月度/季度生产计划
```

平衡需求与供给，确定总体产量。

### 3. MPS（主生产计划）

```
S&OP → 按产品/周拆解的主生产计划
```

决定每个产品在每个时间段的产量。

### 4. MRP（物料需求计划）

```
MPS + BOM + 库存 + 在途 → 净需求
→ 生成：生产订单 + 采购申请
```

核心逻辑见 [BOM 展开算法](../tech/tech-bom-explode-20260816.md)。

### 5. CRP（能力需求计划）

```
生产订单 + 工艺路线 + 工作中心产能 → 工时需求
→ 与可用产能对比，识别瓶颈
```

### 6. APS 排产

详见 [APS 高级计划排程](../systems/aps-overview-20260906.md)。

排产考虑：
- 工序顺序与前置关系
- 资源（设备/人员/工装）约束
- 换型时间
- 交期优先级
- 瓶颈产能

### 7. 工单下达与执行（MES）

见 [MES 业务流程](../mes/mes-workflow-20260816.md)。

## 三、APS 与 MES 分工

| 层级 | 系统 | 时间粒度 | 关注点 |
|------|------|---------|--------|
| 计划 | APS | 天/周 | 产能平衡、交期 |
| 排产 | APS | 小时 | 资源分配、工序顺序 |
| 执行 | MES | 分钟/秒 | 实际报工、过程控制 |

### 闭环

```
APS 排产 → MES 执行 → 实际数据回传 APS → 重排（滚动）
```

## 四、滚动计划

计划不是一次性的，而是滚动更新：

```
每日滚动：重排未开工工单
每周滚动：重排 MPS/MRP
每月滚动：S&OP 复盘
```

## 五、关键接口

| 接口 | 源 → 目标 | 数据 |
|------|----------|------|
| 销售订单 | ERP → APS | 需求 |
| MPS/MRP | ERP → APS | 生产/采购需求 |
| 排产结果 | APS → MES | 工单、工序排程 |
| 实际进度 | MES → APS | 报工、完工 |
| 产能变更 | MES → APS | 设备状态、故障 |

## 六、常见排产策略

| 策略 | 说明 |
|------|------|
| 交期优先 | 按交期倒排 |
| 产能优先 | 瓶颈满负荷 |
| 换型最小 | 同类产品合并生产 |
| 优先级 | 客户/订单优先级 |
| JIT | 拉式生产，按需排产 |

## 七、异常处理

| 异常 | 处理 |
|------|------|
| 订单变更 | 重排受影响工单 |
| 设备故障 | 重排，转其他设备 |
| 物料缺料 | 推迟或拆分工单 |
| 产能不足 | 加班/外协/交期协商 |

## 八、KPI

| 指标 | 说明 |
|------|------|
| 计划达成率 | 实际/计划产量 |
| 交期达成率 | 按时完工占比 |
| 计划变更率 | 计划调整频率 |
| 产能利用率 | 实际/可用产能 |
| 在制品库存 | WIP 数量 |
