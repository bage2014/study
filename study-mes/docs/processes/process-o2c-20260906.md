# 订单到回款流程（O2C - Order to Cash）

> 创建时间：2026-09-06
> 模块：processes

从客户下单到回款的全链路流程，涉及 CRM / ERP / MES / WMS / 财务多系统协同。

## 一、流程全景

```
客户 → 商机 → 报价 → 订单 → 计划 → 生产 → 入库 → 发货 → 开票 → 回款
  CRMP     ERP    ERP   APS    MES    WMS   WMS   财务   财务
```

## 二、阶段拆解

### 1. 商机管理（CRM）

| 步骤 | 系统 | 说明 |
|------|------|------|
| 线索录入 | CRM | 客户线索登记 |
| 商机跟进 | CRM | 销售阶段推进 |
| 客户评估 | CRM | 信用、账期评估 |
| 报价 | CRM/ERP | 产品报价单 |

### 2. 订单录入（CRM/ERP）

| 步骤 | 系统 | 说明 |
|------|------|------|
| 销售订单创建 | ERP | 客户、产品、数量、交期、价格 |
| 信用检查 | ERP | 客户额度、账期校验 |
| 可用性检查 | ERP | 库存/产能可承诺（ATP/CTP） |
| 订单确认 | ERP | 状态：已确认 |

### ATP / CTP

| 类型 | 说明 |
|------|------|
| ATP | Available To Promise，查现有库存 + 在途，可承诺交期 |
| CTP | Capable To Promise，查产能，承诺生产交期 |
| CTP+ | 考虑物料+产能双重约束 |

### 3. 计划排产（APS/ERP）

```
销售订单 → MRP 运算（基于 BOM + 库存 + 产能）
        → 生成：生产订单 + 采购申请
        → 排程：APS 排产 → 生成工单
```

### 4. 生产执行（MES）

见 [计划到生产 P2M](./process-p2m-20260906.md)。

### 5. 完工入库（MES → WMS）

```
MES 工单完工 → 入库单 → WMS 收货上架
```

### 6. 发货（WMS）

```
销售订单 → 发货通知 → 拣货 → 复核 → 打包 → 出库
```

### 7. 开票与回款（财务）

```
发货确认 → 应收单 → 发票开具 → 收款核销
```

## 三、关键接口与数据流转

| 接口 | 源 → 目标 | 数据 |
|------|----------|------|
| 订单同步 | CRM → ERP | 销售订单 |
| 生产需求 | ERP → APS | 订单、物料、产能约束 |
| 生产订单 | ERP → MES | 生产订单转工单 |
| 完工入库 | MES → WMS/ERP | 入库单、完工数 |
| 发货 | ERP → WMS | 发货通知 |
| 出库回传 | WMS → ERP | 实际出库数量 |
| 应收 | ERP → 财务 | 应收单 |

## 四、异常处理

| 异常 | 处理 |
|------|------|
| 客户信用超限 | 暂停订单，走信用审批 |
| 库存不足/产能不足 | 与客户协商交期，或走 CTP |
| 生产延期 | 通知销售，更新交期，触发订单变更 |
| 发货数量不符 | 差异处理，部分发货/补发 |
| 回款逾期 | 信用冻结，催款流程 |

## 五、订单变更

订单下达后客户改数量/交期/产品：

```
1. 订单变更申请
2. 评估：
   ├─ 未投产 → 直接改
   ├─ 已投产 → 评估在制品、物料损失
   └─ 已完工 → 评估库存、返工
3. 审批
4. 同步下游（生产/采购/发货）
5. 版本控制（订单变更记录）
```

## 六、KPI

| 指标 | 说明 |
|------|------|
| 订单准时交付率 | 按时交付订单占比 |
| 订单周期 | 下单→发货平均时长 |
| 订单变更率 | 变更订单占比 |
| 应收周转天数 | 回款速度 |
| 报价→订单转化率 | 商机质量 |
