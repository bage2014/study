# 新品导入流程（NPI - New Product Introduction）

> 创建时间：2026-09-06
> 模块：processes

新产品从概念到量产的全流程，PLM/MES/ERP 深度协同。

## 一、流程全景

```
立项 → 概念 → 设计 → 验证 → 试制 → 小批量 → 量产
 PLM   PLM   PLM    PLM   PLM/MES  MES    MES/ERP
```

Stage-Gate 模型，每阶段有评审门。

## 二、阶段拆解

### 1. 立项（Stage 0-1）

| 活动 | 系统 | 说明 |
|------|------|------|
| 市场需求 | CRM/PLM | 客户需求、竞品分析 |
| 可行性评估 | PLM | 技术、成本、周期 |
| 立项评审 | PLM | 项目立项，创建项目 |

### 2. 概念设计（Stage 2）

| 活动 | 说明 |
|------|------|
| 方案设计 | 概念方案、选型 |
| 概念 BOM | DBOM |
| 成本估算 | 目标成本 |
| 方案评审 | 方案确认 |

### 3. 详细设计（Stage 3）

| 活动 | 系统 | 说明 |
|------|------|------|
| 详细设计 | CAD | 零件设计、装配 |
| EBOM | PLM | 工程 BOM |
| 工艺规划 | PLM | 工艺路线初稿 |
| 图纸发布 | PLM | 图纸签审发布 |

### 4. 验证（Stage 4）

| 活动 | 说明 |
|------|------|
| 仿真/模拟 | CAE | 性能验证 |
| 原型制作 | 打样 | 首件 |
| 测试验证 | DVP | 设计验证计划 |
| 设计评审 | DFM/DFA | 可制造性/可装配性 |

### 5. 试制（Stage 5）

| 活动 | 系统 | 说明 |
|------|------|------|
| EBOM→MBOM 转化 | PLM | 制造 BOM |
| 工艺路线发布 | PLM | 量产工艺 |
| 试制工单 | MES | 试制批次 |
| 试制报告 | MES | 问题记录、改进 |
| 设计变更 | PLM | 迭代优化 |

### 6. 小批量试产（Stage 6）

| 活动 | 说明 |
|------|------|
| 小批量生产 | 验证工艺稳定性 |
| 过程能力 | Cpk 评估 |
| 质量验证 | 全流程检验 |
| 产能爬坡 | 逐步提升产量 |
| PPAP/APQP | 量产批准（汽车行业） |

### 7. 量产（Stage 7）

| 活动 | 说明 |
|------|------|
| SOP 发布 | Standard Operating Procedure |
| 工艺冻结 | 锁定 BOM/工艺版本 |
| 生产转 ERP | 进入正常生产计划 |
| 量产评审 | 正式量产批准 |

## 三、阶段门（Gate）评审

每个 Stage 结束有 Gate 评审：

| Gate | 评审内容 |
|------|---------|
| G1 | 立项：市场、可行性、资源 |
| G2 | 概念：方案、成本、风险 |
| G3 | 设计：EBOM、图纸、规格 |
| G4 | 验证：测试结果、DFM |
| G5 | 试制：MBOM、工艺、试制问题 |
| G6 | 小批量：Cpk、产能、质量 |
| G7 | 量产：SOP、全流程 readiness |

不通过则回退或终止。

## 四、关键文档与交付物

| 阶段 | 交付物 |
|------|--------|
| 立项 | 立项书、需求规格 |
| 概念 | 概念 BOM、方案图 |
| 设计 | EBOM、图纸、规格书 |
| 验证 | 测试报告、DFM 报告 |
| 试制 | MBOM、工艺路线、试制报告 |
| 小批量 | Cpk 报告、PPAP 文件 |
| 量产 | SOP、控制计划 |

## 五、设计变更在 NPI 中的作用

试制/验证阶段变更频繁：

```
发现问题 → 变更申请(ECR) → 评估 → 执行(ECO) → 验证 → 生效
```

NPI 阶段变更频率高，需快速响应。

## 六、跨系统协同

| 阶段 | PLM | MES | ERP |
|------|-----|-----|-----|
| 立项 | 项目管理 | - | 成本估算 |
| 设计 | EBOM/图纸 | - | - |
| 试制 | MBOM/工艺 | 试制工单 | 物料需求 |
| 小批量 | 工艺冻结 | 小批量生产 | 成本核算 |
| 量产 | 版本归档 | 正常生产 | 正常计划 |

## 七、常见行业变体

| 行业 | 特点 |
|------|------|
| 汽车 | APQP、PPAP、IATF16949 |
| 电子 | DFM/DFT、可测试性 |
| 医疗 | ISO13485、法规认证 |
| 半导体 | 工艺平台、良率提升 |
| 装备 | 按单设计（ETO） |

## 八、KPI

| 指标 | 说明 |
|------|------|
| NPI 周期 | 立项→量产时长 |
| 试制问题数 | 设计/工艺问题 |
| 首次合格率 | 试制直通率 |
| 量产爬坡周期 | 到目标产能时长 |
| 设计变更次数 | NPI 阶段变更频次 |
