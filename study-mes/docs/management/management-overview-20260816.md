# 通用管理系统 - 概述

> 创建时间：2026-08-16
> 模块：management

沉淀企业管理系统的通用能力：组织、权限、审批、主数据、配置等，可作为 MES/PLM/ERP 等业务系统的底座参考。

## 一、通用能力地图

```
┌─────────────────────────────────────────────────────┐
│                    业务系统层                        │
│           (MES / PLM / ERP / WMS / SRM)            │
├─────────────────────────────────────────────────────┤
│                    通用能力层                        │
│  组织 │ 权限 │ 审批 │ 主数据 │ 配置 │ 集成 │ 审计 │ 报表 │
├─────────────────────────────────────────────────────┤
│                    基础设施层                        │
│        用户/会话 │ 日志 │ 缓存 │ 消息 │ 文件         │
└─────────────────────────────────────────────────────┘
```

## 二、组织与权限

### 组织模型
| 实体 | 说明 |
|------|------|
| 集团 | 多法人顶层 |
| 法人公司 | 独立法人 |
| 工厂 | 物理生产单元 |
| 部门 | 行政/业务单元 |
| 班组 | 车间最小单元 |
| 岗位 | 职责岗位 |

### 权限模型（RBAC）

```
用户(User) ──┐
             ├──> 角色(Role) ──> 权限(Permission) ──> 资源(Resource)
组(Group) ───┘
```

| 维度 | 说明 |
|------|------|
| 功能权限 | 菜单、按钮、API |
| 数据权限 | 工厂、部门、数据行 |
| 字段权限 | 字段可见/可编辑 |
| 操作权限 | 新增/编辑/删除/导出/审批 |

### 数据权限典型策略
- 按工厂隔离（Plant-level isolation）。
- 按部门层级（树形数据权限）。
- 按归属人（本人/本部门/本部门及下属）。

## 三、审批工作流

### 工作流引擎要素
| 要素 | 说明 |
|------|------|
| 流程定义 | BPMN 描述 |
| 节点 | 任务节点、网关、事件 |
| 处理人 | 用户/角色/部门/上级/发起人自选 |
| 表单 | 业务数据展示与录入 |
| 动作 | 同意/驳回/转办/加签/会签 |
| 超时 | 超时提醒、自动升级 |

### 常见审批模式
| 模式 | 说明 |
|------|------|
| 串行审批 | 逐级审批 |
| 并行会签 | 多人同时审，全部通过 |
| 并行或签 | 多人同时审，任一通过 |
| 条件分支 | 按金额/类型路由 |
| 加签 | 临时增加审批人 |
| 委托 | 代理人代审 |

## 四、主数据管理（MDM）

### 主数据范畴
| 主数据 | 系统 | 说明 |
|--------|------|------|
| 物料 | PLM/ERP | 物料编码、属性 |
| 客户 | CRM/ERP | 客户档案 |
| 供应商 | SRM/ERP | 供应商档案 |
| BOM | PLM/ERP | 物料清单 |
| 工艺路线 | PLM/MES | 工序定义 |
| 组织 | MDM | 公司/工厂/部门 |
| 人员 | HR | 员工档案 |

### 主数据治理原则
- **唯一源**：每类主数据只有一个权威系统。
- **分发机制**：通过接口/事件分发到消费系统。
- **编码规范**：统一编码规则，避免重复。
- **变更闭环**：主数据变更走审批流程。
- **质量监控**：完整性、一致性、时效性监控。

## 五、配置管理

### 配置分层
| 层级 | 说明 | 示例 |
|------|------|------|
| 系统配置 | 全局参数 | 公司名称、时区 |
| 业务配置 | 业务参数 | 单号规则、容差 |
| 模块配置 | 模块开关 | 是否启用 SPC |
| 用户配置 | 个人偏好 | 列表列、默认筛选 |

### 单号生成规则
| 规则 | 示例 |
|------|------|
| 前缀 + 日期 + 流水 | WO20260816-0001 |
| 业务码 + 年 + 流水 | PO-2026-00001 |
| 雪花算法 | 分布式唯一 ID |

## 六、集成与接口

### 集成模式
| 模式 | 说明 | 适用 |
|------|------|------|
| 同步接口 | REST/RPC，实时 | 查询、即时操作 |
| 异步消息 | MQ/Kafka，解耦 | 事件通知、数据同步 |
| 批量同步 | ETL/定时任务 | 大数据量同步 |
| 文件交换 | CSV/XML | 老旧系统、外部伙伴 |
| API 网关 | 统一入口、鉴权 | 对外开放 |

### 集成设计原则
- 接口契约优先（OpenAPI/Proto）。
- 幂等设计（重复调用安全）。
- 异常重试与死信队列。
- 版本管理（v1/v2 兼容）。
- 链路追踪（traceId 贯穿）。
